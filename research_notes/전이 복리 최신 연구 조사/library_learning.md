# Library learning and reusable abstraction for cross-domain transfer (June–November 2026, with precursors)

Scope note. Every citation below was opened (arXiv abstract page, arXiv HTML full text, ACL Anthology page, or the author's publication page). Where only the abstract page was read, that is stated and numbers are absent for that reason. "Precursor" marks anything dated before June 2026. Searches covered arXiv cs.AI/cs.LG/cs.PL/cs.RO, Kevin Ellis's and Xujie Si's publication pages, NeurIPS/ICML/ICLR/EACL/COLM 2026 listings, and citation trails of DreamCoder, LILO, Stitch, Babble, REGAL, InnateCoder.

Headline (plain statement). In the window June–November 2026 I found **no paper in the symbolic DreamCoder / Stitch / Babble / LILO lineage that measures forward transfer of a learned library to a genuinely different held-out domain and shows it beating a from-scratch learner**. Every quantitative transfer result found in the window comes from LLM-agent skill/memory libraries (text or code skills retrieved into an LLM's context), and almost all of those test held-out *tasks within the same benchmark*, not held-out domains. The two closest symbolic-leaning results (DreamProver, NEO) learn a library per domain or per environment and do not test cross-domain reuse. The strongest negative results in the window and immediately before it say that (a) in-context library learning does not beat plain prompting at equal compute, (b) low-level, instance-specific carried content causes negative transfer while only abstract procedural content transfers, and (c) DreamCoder-style retrospective compression does not match how humans choose abstractions when the task distribution shifts.

---

## Key Question 1: Which post-June-2026 papers measure forward transfer to a held-out domain, and how large is it?

### Takeaway
Post-June-2026 forward-transfer measurements exist only for LLM-agent skill libraries, and the held-out set is nearly always unseen tasks from the same benchmark or environment family. The largest clean number is ASPIRE's zero-shot LIBERO-Pro Long result (overall 0.047 with an empty library to 0.305 with a 90-task library), which is a held-out *task* set in the same simulator, not a new domain. No symbolic library-learning paper in the window reports a held-out-domain transfer number.

### Cited Findings

**In-window (June–November 2026)**

- **ASPIRE: Agentic Skills Discovery for Robotics** (Lu, Wu, Kou, Fu, Xiao, Mandlekar, Xu, Shi, Goldberg, Chen, Chowdhury, Zhu, Fan, Wang; arXiv 2607.00272, submitted 30 Jun 2026). Skills are stored as in-context guidance (failure signature, when-to-apply condition, repair strategy, optional code sketch) admitted to a shared library by a coordinator. Zero-shot on held-out LIBERO-Pro Long (Table 5, macro-averaged): empty library N=0 gives Pos 0.00 / Task 0.094 / overall 0.047; full library N=90 (built on LIBERO-90) gives Pos 0.226 / Task 0.383 / overall 0.305; success rises monotonically with N=0,25,50,90. Prior method CaP-Agent0 overall 0.038. Real robot drawer task: 0/20 without a simulation-discovered skill, 11/20 with it. Given by humans: a fixed predefined API of perception/geometry/motion-planning primitives (CaP-X, MuJoCo Playground), benchmark splits, success criteria, initial library templates and prompts; frozen Claude Opus 4.6 with 1M context at runtime. Stated limits: per-task zero-shot uneven (some tasks stay at 0 across all library sizes), library entries can become stale or misleading, which the authors say may explain non-monotonic per-task trends. — [arXiv 2607.00272 HTML](https://arxiv.org/html/2607.00272v1)
- **SkillGLoW: Procedural-Family Skill Consolidation for Self-Improving Agents on Long-Horizon Task Streams** (Yan, Zhang, Du, Zhou; arXiv 2609.02217, submitted 2 Sep 2026). Clusters task-specific textual skills into "procedural families," compresses each into a de-instantiated prior, regenerates instance details per task, and uses a commit gate that admits a prior only if execution shows no degradation. Unseen ALFWorld tasks: 73.9% to 83.9% (+10 points) with the unmodified library vs no-library baseline; average +17.2 points on hard tasks across four benchmarks (math, terminal automation, software repair, embodied control), +18.0 with local regeneration; beat a single-document optimizer in 15 of 21 cells (lost 6). Authors' conclusion: "what transfers is procedure rather than task memory." The abstract does not report any cross-domain (genuine domain change) test; held-out is within ALFWorld. — [arXiv 2609.02217](https://arxiv.org/abs/2609.02217)
- **Reflect, Revise, Reuse: Training-Free Skill Evolution for GUI Agents** (Chen et al.; arXiv 2609.17653, submitted 15 Sep 2026). EvoSkill-GUI edits multi-file skill packages from execution feedback. Reported maximum gains +16.2% (MobileWorld), +6.0% (AndroidWorld), +10.5% (OSWorld); authors say evolved libraries benefit related tasks. A search snippet reported a held-out MobileWorld split of 22/30 (73.3%) vs pass@3 baseline 12/30 (40.0%); the abstract page does not show this breakdown, so treat the 22/30 figure as unverified from the primary page. No negative-transfer statement on the abstract page; the search snippet said retrieval mismatch is flagged as a potential negative-transfer source. — [arXiv 2609.17653](https://arxiv.org/abs/2609.17653)
- **EvoAgentBench: Benchmarking Agent Self-Evolution via Ability Transfer** (Gao et al.; arXiv 2607.05202, submitted 6 Jul 2026). Multi-domain (web research, algorithmic reasoning, software engineering, knowledge work), 528/267 train/test split where every test task is backed by verified training-side "Ability" support; two scaffolds, three backbones. Finding: "no current automatic method sustains positive gain in all settings"; curated Ability content transfers reliably across model families. Abstract page gives no per-cell numbers. — [arXiv 2607.05202](https://arxiv.org/abs/2607.05202)
- **Beyond Domains: Reusing Web Skills via Transferable Interaction Patterns** (He, Cui, Wu, Ma, Lu, Li, Ding, Chowdhury; arXiv 2606.17645, submitted 16 Jun 2026). SkillMigrator stores each web skill with a structural sketch of page layout and retrieves by layout similarity to reuse across websites. Measured: average LLM actions on successful trajectories at matched success rate; reduction 8–10% on WebArena and Mind2Web vs state of the art. No separate held-out-site transfer number on the abstract page. — [arXiv 2606.17645](https://arxiv.org/abs/2606.17645)
- **Offline Multi-agent Continual Cooperation via Skill Partition and Reuse** (Xiao, Yuan, Xue, Yin, Yu; arXiv 2606.25389, submitted 24 Jun 2026, listed as ICML 2026). COMAD extracts reusable coordination skills with an auto-encoder and expands the library to reduce interference; claims superior forward and backward transfer across task streams. Abstract gives no numbers. Search-snippet text (not confirmed on the abstract page) says fixed-size skill-library methods ODIS and HiSSD "perform worse than FS [from scratch]" on forward transfer due to plasticity loss, while COMAD exceeds OWL by actively reusing skills. — [arXiv 2606.25389](https://arxiv.org/abs/2606.25389)
- **RELIC: Revealed Principles for Learning Interpretable Composable Skills in Multi-Agent Planning** (Kiet et al.; arXiv 2607.16745, v1 18 Jul 2026, v2 30 Jul 2026; LM4Plan Workshop at ICML 2026). Distills programmatic skills into textual "principles" re-instantiated under each agent's own interface; evaluated on routing, scheduling, combinatorial optimization, distributed coordination. Abstract page gives no transfer numbers. — [arXiv 2607.16745](https://arxiv.org/abs/2607.16745)
- **Joint Learning of Hierarchical Neural Options and Abstract World Model** (Piriyakulkij, Lehrach, Ellis, Murphy; arXiv 2602.02799, v1 2 Feb 2026, v2 11 May 2026; NeurIPS 2026 per Ellis's page). AgentOWL on Montezuma's Revenge, Pitfall, Private Eye (OCAtari). Zero-shot to a new start state in Private Eye after learning one connecting option (Table 1, 100 episodes, goals 1–3): AgentOWL with new option 1.00/1.00/1.00 vs without 0.02/0.01/0.26 vs goal-conditioned DQN 0.00/0.00/0.00. No new-game or held-out-goal experiment. Given by humans: OCAtari object types and bounding boxes plus a manually added room-number object, hand-ordered goal list, goal predicates as reward, a Manhattan-distance heuristic in the Q-network, example feature prompts. Baselines outperform AgentOWL at low sample budgets. — [arXiv 2602.02799 HTML](https://arxiv.org/html/2602.02799v2); venue from [Ellis publications page](https://www.cs.cornell.edu/~ellisk/)
- **Learning to Theorize the World from Observation** (Baek, Lee, Baek, Lee, Ahn; arXiv 2605.03413, v1 5 May 2026, v3 17 Sep 2026, v4 5 Oct 2026). NEO learns discrete primitives (VQ-VAE codes) whose meaning comes from a shared transition model, with MDL program selection, from raw (x, y) observation pairs only; no DSL, labels, or segmentation. Compositional OOD transfer in GridWorld at α=0.33: NEO 0.933 vs monolithic baselines 0.000; length OOD 0.845 (NEO-S 0.907). Arithmetic compositional OOD at α=0.66: 0.573 vs ~0 baselines; length OOD only 0.019 for NEO, 0.696 with test-time sampling. All transfer is recombination of primitives *within the same environment*; no cross-environment reuse is tested. Authors call it an early proof of concept on synthetic benchmarks. — [arXiv 2605.03413 HTML v4](https://arxiv.org/html/2605.03413v4)
- **Discovery by Dreaming: Cross-Domain Recombination in Artificial Memory** (Zahn, Evans, Eagleman; arXiv 2607.16256, v1 28 Jun 2026, v2 21 Jul 2026). Two systems: DREAMS (LoRA fine-tuning replay) and SAPIENCE (symbolic engine replaying structured knowledge objects). Symbolic arm: 85.7% of novel cross-domain connections surfaced, +21 pp over baseline. Neural arm: +5.64 pp overall, up to +14.5 pp on cross-domain subtasks (GSM8K unseen math). Finding: "cross-domain consolidation creates value, while within-domain rehearsal does not"; prepending the same material in-context to a 671B model reversed the gain. This is memory recombination, not program-library learning, and the abstract does not say what humans curated. — [arXiv 2607.16256](https://arxiv.org/abs/2607.16256)

**Precursors (before June 2026) that in-window work builds on**

- **DreamProver: Evolving Transferable Lemma Libraries via a Wake-Sleep Theorem-Proving Agent** (Zhang, Sun, Bi, Geng, Ma, Li, Si; arXiv 2604.26311, submitted 29 Apr 2026; COLM 2026 per Si's page). Direct DreamCoder-wake-sleep successor for Lean 4. Libraries learned once per domain, kept under 100 lemmas via LRU forgetting (inequality 41 lemmas, 35 used; number theory 75, 29 used; combinatorics 39, 19 used); 58% of lemmas reused on test, covering 71% of solved theorems. Ablation on inequality (three benchmarks pooled): full 104 solved; no library 55; no library optimization 76; LEGO-Prover-style retrieval 61. Against Hilbert: +20% (inequality), +114% (number theory), +50% (combinatorics). **No cross-domain experiment: each library is trained and tested on the same domain.** Given by humans: Lean 4 statements, mathlib, 100 training problems per domain, prompt templates, GPT-5.3-Codex at runtime. — [arXiv 2604.26311 HTML](https://arxiv.org/html/2604.26311v1); venue from [Xujie Si publications](https://www.cs.toronto.edu/~six/pubs.html)
- **Learning Abstractions for Hierarchical Planning in Program-Synthesis Agents (TheoryCoder-2)** (Ahmed, Irie, Tenenbaum, Bates, Gershman; arXiv 2602.00929, submitted 31 Jan 2026). Token cost totals across 13 tasks: TC-2 Full 121,529 vs no-curriculum 268,241 vs WorldCoder 437,719 vs LLM+P 443,307 vs plain LLM policy 157,206. Transfer within families: move_to learned in Labyrinth reused in Maze and Sokoban; BabyAI Pickup+Unlock abstractions composed for the Boss level drop tokens from ~8,500 and ~33,000 to ~2,000; MiniHack move_to reused on 15x15, Traps, Monster. Given by humans: object-oriented text state, natural-language goal prompt, toy PDDL few-shot templates, per-domain descriptions, hand-grouped and hand-ordered curriculum, GPT-4o, Fast Downward, BFS. All agents including TC-2 failed Combined Skills 2; plain LLM policy is cheaper on simple tasks (Maze 3,518 vs 19,737). Abstraction quality not measured quantitatively. — [arXiv 2602.00929 HTML](https://arxiv.org/html/2602.00929)
- **Memory Transfer Learning: How Memories are Transferred Across Domains in Coding Agents** (Kim, Kang, Kim, Yang, Ren, Hwang; arXiv 2604.14004, submitted 15 Apr 2026). Unified memory pool from heterogeneous domains, 4 memory representations, 6 coding benchmarks: cross-domain memory improves average performance by 3.7%; gains come mainly from meta-knowledge (validation routines) rather than task-specific code; low-level traces "often induce negative transfer due to excessive specificity"; effect scales with pool size. — [arXiv 2604.14004](https://arxiv.org/abs/2604.14004)
- **Test-Time Learning with an Evolving Library (EvoLib)** (Xu, Sordoni, Singh, Gero, Galley, Yuan, Gao; arXiv 2605.14477, v1 14 May 2026, v3 6 Nov 2026; NeurIPS 2026). Shared library of modular skills and insights extracted from the LLM's own trajectories, with weighting/consolidation that lets specific abstractions become more general; gains on math, code, multi-turn agentic tasks. Abstract gives no numbers or cross-domain test. — [arXiv 2605.14477](https://arxiv.org/abs/2605.14477)

### Inferences
- The only in-window number that approaches "held-out domain" is ASPIRE's 0.047 to 0.305, and even that is held-out tasks in the same simulator with the same hand-built API. Nothing measured transfer from, e.g., a graphics DSL to a text DSL.
- The pattern across SkillGLoW, Memory Transfer Learning, EvoAgentBench and ASPIRE is consistent: what carries is a de-instantiated *procedure* (how to diagnose, verify, repair), not instance-level content or statistics of past solutions.
- In every in-window system the library is read by a frontier LLM at runtime; the transfer effect is inseparable from the LLM's own prior. None of these results bear directly on a no-LLM symbolic predictor.

### Gaps
- No paper found in June–November 2026 that trains a Stitch/Babble/DreamCoder-style library on one DSL domain and tests on a different DSL domain. The DreamCoder authors' own "cross-domain library / language of thought by metalearning" direction remains unrealized in the literature found.
- COMAD's forward-transfer vs from-scratch numbers and EvoAgentBench's per-cell numbers are in the full PDFs, which were not read.
- Reflect-Revise-Reuse 22/30 vs 12/30 held-out figure not confirmed on the primary page.

## Key Question 2: Does any work show library/abstraction reuse beating a from-scratch learner on genuinely different domains (not variants)?

### Takeaway
No. Within the window, every reuse-beats-scratch result is on variants: unseen tasks of the same benchmark (SkillGLoW/ALFWorld, ASPIRE/LIBERO, EvoSkill-GUI), new start states in the same game (AgentOWL), or recombinations within the same synthetic environment (NEO). The two results that cross domains are not library learning in the program-synthesis sense: Memory Transfer Learning (+3.7% average across coding benchmarks, meta-knowledge only) and Discovery by Dreaming (memory recombination, +21 pp symbolic arm). The nearest symbolic system, DreamProver, deliberately does not cross domains.

### Cited Findings
- DreamProver learns a separate library per domain and evaluates each on its own domain; the authors list "unknown domains that need several libraries" as a difficulty for smaller models, not as a tested capability. — [arXiv 2604.26311 HTML](https://arxiv.org/html/2604.26311v1)
- SkillGLoW's only transfer evidence is unseen ALFWorld tasks (+10 points); it does not test genuine domain change. — [arXiv 2609.02217](https://arxiv.org/abs/2609.02217)
- ASPIRE's held-out set (LIBERO-Pro Long) shares the simulator, API and object set with the LIBERO-90 source; some held-out tasks stay at 0 across all library sizes. — [arXiv 2607.00272 HTML](https://arxiv.org/html/2607.00272v1)
- AgentOWL: no new-game or held-out-goal experiment; the 1.00 vs 0.02 result is new start state in Private Eye. — [arXiv 2602.02799 HTML](https://arxiv.org/html/2602.02799v2)
- NEO's 0.933 compositional-OOD transfer is within GridWorld; cross-environment reuse of primitives is not tested. — [arXiv 2605.03413 HTML v4](https://arxiv.org/html/2605.03413v4)
- Memory Transfer Learning: cross-domain pooled memory +3.7% average; the gain is meta-knowledge; task-specific code does not transfer. — [arXiv 2604.14004](https://arxiv.org/abs/2604.14004)
- Discovery by Dreaming: cross-domain consolidation creates value, within-domain rehearsal does not (symbolic arm +21 pp; neural +5.64 pp overall). — [arXiv 2607.16256](https://arxiv.org/abs/2607.16256)
- TheoryCoder-2's reuse is within game families (Labyrinth to Maze/Sokoban; BabyAI levels; MiniHack levels), with a human-ordered curriculum. — [arXiv 2602.00929 HTML](https://arxiv.org/html/2602.00929)
- **A Compositional Framework for Open-ended Intelligence** (Momennejad, Raileanu; arXiv 2606.15386, v1 13 Jun 2026, v2 16 Jun 2026) is a position paper: it formalizes a compositional closure L(P, C) over a finite primitive set and proposes "next primitive prediction" as a training objective; no experiments. A search snippet attributed to it the distinction between library learning ("does a shared library compress programs for one task") and transfer ("does a primitive reappear in a different task family") and named DreamCoder and Stitch as predecessors; the abstract page does not show those passages, so that attribution is unverified. — [arXiv 2606.15386](https://arxiv.org/abs/2606.15386)

### Inferences
- The field's post-2026 evidence for "past learning makes a NEW domain faster" is essentially confined to settings where a frontier LLM supplies the cross-domain bridge. Remove the LLM and there is no published demonstration in the window.
- Where a cross-domain effect is shown without an LLM at runtime (Discovery by Dreaming's SAPIENCE arm), the mechanism is recombination of already-structured knowledge objects, not induction of a shared DSL.

### Gaps
- Full text of Discovery by Dreaming not read; what the symbolic "knowledge objects" are and how much was hand-curated is unknown.
- No failed-replication paper of DreamCoder/LILO/Stitch cross-domain claims found; the original papers never claimed cross-domain transfer, so there is nothing to replicate.

## Key Question 3: What did the system receive for free (primitives, DSL, object segmentation)?

### Takeaway
Every system found receives a hand-built symbolic substrate: a DSL or API of primitives, an object-centric or text state representation, and usually a human-ordered curriculum or task split. The single exception (NEO) learns primitives from raw pixels/integers but only on tiny synthetic worlds with short programs.

### Cited Findings
- DreamProver: Lean 4, mathlib, 100 training theorems per domain, prompt templates, GPT-5.3-Codex. — [arXiv 2604.26311 HTML](https://arxiv.org/html/2604.26311v1)
- TheoryCoder-2: object-oriented text-based state (explicit assumption), NL goal prompt, toy PDDL few-shot templates, per-domain NL descriptions, hand-grouped and hand-ordered curriculum, GPT-4o, Fast Downward, BFS; hand-designed Oracle abstractions as reference; predicate classifiers brittle to how objects are represented (open doors as "open_door" led to wrong assumptions). — [arXiv 2602.00929 HTML](https://arxiv.org/html/2602.00929)
- AgentOWL: OCAtari object types and bounding boxes plus a manually added "room number" object; a few hand-selected rooms per game; hand-ordered goal list with goal predicates as rewards; Manhattan-distance heuristic in the Q-network; author-written feature prompts; requires symbolic input, not pixels. — [arXiv 2602.02799 HTML](https://arxiv.org/html/2602.02799v2)
- ASPIRE: fixed API of perception, geometry and motion-planning primitives (CaP-X, MuJoCo Playground); rules forbidding simulator ground truth; initial skill templates and pipeline prompts; frozen Claude Opus 4.6 (1M context). The API bounds what can be expressed. — [arXiv 2607.00272 HTML](https://arxiv.org/html/2607.00272v1)
- Prospective Compression (human study): six primitives (blank, horizontal line, vertical line, diagonal, border square, triangle), three binary operators (add, subtract, overlap), four unary operators (invert, three reflections), 10x10 binary grids. — [arXiv 2605.09985 HTML](https://arxiv.org/html/2605.09985v1)
- NEO: only raw (x, y) observation pairs; primitives are VQ-VAE codes; encoder/decoder pretrained; no DSL, no segmentation, no labels; but domains are a 10x10 GridWorld, integer multiplication chains over {x2, x3, x5, x7}, and CIFAR-10 with 8 editing ops, programs of length 1–3 in training. — [arXiv 2605.03413 HTML v4](https://arxiv.org/html/2605.03413v4)
- SkillGLoW, EvoSkill-GUI, SkillMigrator, RELIC, EvoLib: abstract pages do not describe human-supplied seed skills; all run a frontier LLM at inference, which is the dominant given. — [2609.02217](https://arxiv.org/abs/2609.02217), [2609.17653](https://arxiv.org/abs/2609.17653), [2606.17645](https://arxiv.org/abs/2606.17645), [2607.16745](https://arxiv.org/abs/2607.16745), [2605.14477](https://arxiv.org/abs/2605.14477)

### Inferences
- Object identity and attribute slots are given in every world-model-style system found (OCAtari, text state, Lean statements). None of them has to discover that "attributes are classes of tokens that replace each other under actions," which is the step ATANOR's representation-birth probe is working on.

### Gaps
- Human-provided components of Discovery by Dreaming, COMAD, EvoAgentBench not read (abstract only).

## Key Question 4: Any negative results or failed replications?

### Takeaway
Yes, several, and they cluster into three lessons: in-context library learning does not beat plain prompting at equal compute; instance-specific carried content causes negative transfer while only abstract procedure transfers; and DreamCoder-style retrospective compression does not match human abstraction choice when the task distribution shifts.

### Cited Findings
- **Is This LLM Library Learning? Evaluation Must Account For Compute and Behaviour** (Berlot-Attwell, Sesterhenn, Rudzicz, Si; EACL 2026 Long Papers pp. 3534–3568, Rabat, March 2026, Oral). Studies three separately published in-context library learning systems; none consistently beats directly prompting the model, and accuracy gains "often vanish or reverse" once compute is accounted for; for LEGO-Prover, no evidence that learned lemmas are directly reused and evidence against reuse by adapting examples; calls for equal compute budgets for baselines and behavioural analysis. — [ACL Anthology 2026.eacl-long.163](https://aclanthology.org/2026.eacl-long.163/). Precursors by the same group: [Library Learning Doesn't (arXiv 2410.20274)](https://www.arxiv.org/pdf/2410.20274) and [LLM Library Learning Fails: A LEGO-Prover Case Study (arXiv 2504.03048)](https://arxiv.org/abs/2504.03048v1).
- **Prospective Compression in Human Abstraction Learning** (Hernandez Cano, Zareski, El Amouri, Zhao, Mascini, Sansone, Pu, Zhao, Kryven; arXiv 2605.09985, submitted 11 May 2026, under review NeurIPS 2026). Two Prolific experiments (N=30 each; 26 and 25 analyzed). Six models: no-library enumeration, Retrospective Compression (DreamCoder-style top-k by compression utility), Greedy Library Learning, Probabilistic Library Learning, LLM-PS (GPT-5.2), LLM-PS-H (with history). Experiment 1 (sequential curriculum): RC approximates oracle compression and so do humans. Experiment 2 (operator-group curriculum): human helpers' corpus compression "consistently exceeds" RC and both LLM models and tracks oracle; authors conclude retrospective compression alone cannot explain human abstraction. No-library fails from trial 7/9; Greedy fails from trial 9 in Exp. 2; Probabilistic fails on the last four trials of Exp. 1. No single fit statistic reported; model comparison is by compression curves. Limitation: one constrained visual domain; no generative-process learner implemented. — [arXiv 2605.09985 HTML](https://arxiv.org/html/2605.09985v1)
- Memory Transfer Learning: low-level traces often induce negative transfer; only abstract insights generalize. — [arXiv 2604.14004](https://arxiv.org/abs/2604.14004)
- EvoAgentBench: no automatic self-evolution method sustains positive gain in all scaffold x backbone x domain settings. — [arXiv 2607.05202](https://arxiv.org/abs/2607.05202)
- TheoryCoder-2: all agents including TC-2 fail BabyAI Combined Skills 2; plain LLM policy cheaper on simple tasks; without curriculum cost on Combined Skills 1 rises from 1,961 to 44,725 tokens; WorldCoder uses more tokens than the raw LLM approach on several tasks. — [arXiv 2602.00929 HTML](https://arxiv.org/html/2602.00929)
- ASPIRE: library entries can become stale, redundant or misleading, which may explain non-monotonic per-task zero-shot trends; some held-out tasks remain at 0 at every library size. — [arXiv 2607.00272 HTML](https://arxiv.org/html/2607.00272v1)
- AgentOWL: baselines outperform it at low sample budgets; fails on hard goals without first learning prerequisite sub-goals. — [arXiv 2602.02799 HTML](https://arxiv.org/html/2602.02799v2)
- DreamProver: no cross-domain test; no with/without-library ablation outside inequality; Olympiad geometry stays at 7/19. — [arXiv 2604.26311 HTML](https://arxiv.org/html/2604.26311v1)
- Search-snippet-only (not opened; treat as leads): SkillsVote (arXiv 2605.18401) reportedly finds exposing an entire transferred library produces more harmful than helpful deltas until filtered by task relevance; SkillGenBench (arXiv 2605.18693, submitted 18 May 2026, abstract opened) reports "the difficulty of reusable skill distillation" in the task-agnostic regime where the library is built before held-out tasks are revealed, but gives no numbers on the abstract page. — [SkillGenBench abstract](https://arxiv.org/abs/2605.18693); SkillsVote not opened.

### Inferences
- The ATANOR "life vs none vs shuffled" judge is exactly the methodology the EACL paper demands (equal budget, behavioural check for actual reuse). A NO-GO under that judge is consistent with what the field finds when it applies the same standard.

### Gaps
- No formal failed replication of DreamCoder, LILO, Stitch or Babble was found; the Si-group negative results target LLM in-context library learning, not the symbolic compressors.
- Could not find any paper in the window that reports "library learned on domain A hurt learning on domain B" for a symbolic (non-LLM) learner.

## One-line judgements for the ATANOR predictor

Context: symbolic per-action effect predictor, Bayesian averaging over small explanation sets, six tool-call worlds, no LLM at runtime; three attempts to carry explanation-form priors across worlds (prior on explanation size and cell kind; per outcome kind; whole action pattern with input roles) did not beat an empty mind on dev seeds.

| Paper | Helps? | Why (one line) |
|---|---|---|
| DreamProver (2604.26311) | No | Per-domain libraries, LLM at runtime, never tested across domains; confirms that even the closest wake-sleep successor does not claim cross-domain reuse. |
| TheoryCoder-2 (2602.00929) | Indirect | Reuse happened only across hand-curated variant levels sharing an object-text schema; its failures (brittle predicates, all-agents-fail on composed skill 2) match ATANOR's experience that form priors do not carry. |
| AgentOWL (2602.02799) | Indirect | Shows options compose for new *goals* in the same world given human object slots; nothing about new worlds. |
| NEO / Learning to Theorize (2605.03413) | Partly | Primitives discovered from raw observation recombine to 0.93 OOD inside one world; the useful idea is MDL program selection over a shared transition model, but it does not test cross-world reuse. |
| Prospective Compression (2605.09985) | Yes, as diagnosis | Retrospective compression (what ATANOR's carried priors amount to) matches humans only under a stationary curriculum; under operator-group shift it underperforms. Suggests the carrying unit should target the *next* world's structure, not summarize past ones. |
| Memory Transfer Learning (2604.14004) + SkillGLoW (2609.02217) | Yes, as direction | Both find that only de-instantiated procedure transfers and instance-level content causes negative transfer; ATANOR's three carried units were all instance-statistics of past explanations. |
| EACL 2026 "Is This LLM Library Learning?" | Yes, as methodology | Validates the equal-budget life-vs-none-vs-shuffled judge; NO-GO is the honest outcome most systems would show under it. |
| ASPIRE (2607.00272) | No | Transfer is within one simulator and API with a 1M-context LLM reading the library. |
| Discovery by Dreaming (2607.16256) | Maybe | The one no-LLM-at-runtime symbolic arm showing a cross-domain effect, but it recombines already-structured knowledge objects; full text unread. |
| EvoAgentBench, SkillMigrator, RELIC, EvoLib, EvoSkill-GUI | No | LLM skill retrieval; held-out tasks, not domains. |
| A Compositional Framework for Open-ended Intelligence (2606.15386) | Framing only | Position paper; useful vocabulary (library learning = compression within a task family; transfer = primitive reappearing in another family) if the snippet attribution holds. |

Net: nothing published June–November 2026 supplies a symbolic, no-LLM mechanism by which a library learned in worlds A–E makes world F faster to learn, and the strongest in-window evidence says the thing that transfers is procedure (how to find and check an explanation), not the form or statistics of past explanations.
