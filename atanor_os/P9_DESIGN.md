# P9 설계 — 내부 개념과 영어 명령문의 연결 (2026-10-24, 사전 공개, 구현 전)

## P8b에서 넘겨받은 것 (`P8B_REPORT.md`)
- 기반 표현은 **R1(E1만으로 만든 파일 몸 표현, 2,107 B)을 고정**한다. 수정된 표현은 파일 몸에서 행동 근거로 믿을 수 없다.
- 영어는 개념 **번호가 아니라 정의**(원시 원자 집합의 sha256)에 붙인다. 번호는 수정 때 다시 매겨졌다(c4 ↔ c5).
- 정의가 안정된 개념은 파일 몸의 다섯 개다. 화면 몸은 개념이 0개다. **P9 v1은 파일 몸만 시험한다.** 화면 몸에서 영어를 원시 조건에 잇는 일은 "내부 개념과 영어의 연결"이 아니므로 여기서 다루지 않는다.
- P9 동안 표현을 수정하지 않는다.

## 질문
교사와 Qwen을 끈 상태에서, ATANOR는 처음 보는 영어 명령문을 자기 내부 표현으로 해석하고 그대로 행동할 수 있는가? 며칠 뒤에도 저장한 연결만으로 같은 일을 하는가? 내부 개념이 원시 원자만 쓸 때보다 연결에 무엇을 더하는가?

## 과제 범위 (좁게 고정)
- **명령문**: 파일 작업 공간에 대한 영어 명령 한 문장. 예: "Copy every csv file into a new folder called keep."
- **도구**: copy, move, delete 세 가지(몸의 도구). 대상은 작업 공간에 있는 객체다.
- **해석** = (도구, 고를 객체들의 집합, 목적 폴더 이름(copy·move만)).
- **장면**: 평가기가 만든 새 작업 공간. 파일 4–6개(확장자 섞임)와 폴더 1개(안에 파일 1개). 목적 폴더는 아직 없다.

## ATANOR가 하는 일 (`agent/language.py`, 교사·평가 모듈 import 금지)
1. **입력**: 문장의 토큰(소문자, 영숫자 단위)과, 장면의 각 객체에 대해 R1 표현으로 계산한 원자(원시 원자 + R1 개념 원자, 1항만).
2. **도구 연결**: 단어와 도구의 공기를 피드백으로 센다. 도구 이름 문자열은 불투명한 식별자로 다루고, 단어와 문자열을 비교하지 않는다.
3. **대상 연결**
   - 단어마다, 그 단어가 나온 훈련 문장에서 **고른 객체 모두에 있던 원자**의 교집합을 그 단어의 뜻으로 둔다.
   - 장면의 모든 후보에 늘 있는 원자는 뜻에서 뺀다.
   - 해석할 때는 뜻이 있는 단어들의 원자를 모두 만족하는 객체를 고른다.
4. **처음 보는 단어**
   - 훈련에서 "토큰 문자열이 고른 객체의 원시 속성 값과 같다"는 관계가 얼마나 믿을 만했는지 배운다.
   - 그 신뢰도가 0.8 이상이면, 처음 보는 토큰이 장면 객체의 속성 값과 같을 때 그 값을 조건으로 쓴다.
   - 이 관계를 쓸지는 훈련 통계가 정한다.
5. **목적 폴더**: 목적 폴더 이름 바로 앞에 오는 단어를 훈련에서 센다. 해석할 때 뜻이 없는 토큰 가운데 앞 단어 점수가 가장 높은 것을 고른다. 그 도구가 훈련에서 목적지를 가졌던 비율이 0.5 미만이면 목적지를 두지 않는다.
6. **행동**
   - 해석한 도구의 가장 지지가 큰 R1 규칙의 효과를 (객체, 목적 폴더/객체 이름)에 적용해 목표 상태를 만든다.
   - R1 모델의 계획기로 그 상태에 도달한다. 예를 들어 목적 폴더를 먼저 만드는 일은 계획기가 찾는다.
   - 사람이 쓴 "도구 → 목표" 대응은 없다.
7. **훈련 순서**: 매 문장마다 ATANOR가 먼저 해석하고 시험 공간에서 행동한다. 그 뒤 교사의 정답 해석을 받아 갱신한다.

## 교사와 자료
- **교사**: 이 세션의 Claude. 훈련 문장 약 80개를 쓰고 정답 해석을 붙인다(`teach/p9_sentences.py`, 훈련 전용).
- **훈련 확장자**: txt, csv, md.
- **평가 문장**: 교사 문맥을 받지 않은 별도 에이전트가 레포 밖(`sealed/`)에 쓴다. 실행 전에는 sha256만 공개한다.
  - **즉시 세트** 30문장, **지연 세트** 30문장. 같은 지시로 쓰고 서로 다른 문장이다.
  - 확장자에 log·json(훈련에 없음)을 포함한다.
  - 훈련 문장과 정확히 같은 문장은 제외하고, 그 수를 보고한다.
- **평가 정답**: 문장 작성자가 붙인 구조화 정답(도구, 선택자 = {종류: 파일·폴더·전부, 확장자: 값·전부}, 목적 폴더)이다. 장면에서 선택자를 만족하는 객체가 정답 집합이다. **정답은 사후에 고치지 않는다**(`EVALUATION_POLICY.md`의 원칙: 정답 기준은 평가 전에 고정).

## 조건 (평가는 모두 교사·Qwen 끔)
| 조건 | 설명 |
|---|---|
| **CONCEPT** | R1 원시 원자 + R1 개념 원자로 연결(1차) |
| FLAT | 같은 학습기, 원시 원자만(개념 원자 없음). 개념의 기여를 분리 |
| NONE | 연결 없음: 훈련에서 가장 흔한 도구, 모든 파일 선택, 마지막 토큰을 목적지로 |
| ORACLE | 정답 해석 → 같은 R1 행동 경로. 행동 단계의 상한 |

## 측정 (따로 보고)
1. **문장 해석 점수**: 도구·대상 집합·목적지가 모두 맞은 비율. 세 구성 요소의 정확도를 따로 적는다. 훈련에 나온 확장자만 쓴 문장과 처음 보는 확장자를 쓴 문장을 나눠 적는다.
2. **실제 행동 성공률**: 평가기의 참 목표(정답 해석에서 계산)가 끝 상태에서 성립하고, 고르지 않은 객체가 바뀌지 않은 비율.
3. **며칠 뒤 재사용률**: 연결 파일(`lexicon_CONCEPT.json`)을 훈련 직후 sha256과 함께 동결한다. **72시간 이상 지난 뒤** 지연 세트로 다시 시험한다. 시험기는 경과 시간과 sha가 맞지 않으면 실행을 거부한다. 지연 세트 원본은 그때 처음 연다.
4. 유효성: 교사 import·LLM/로컬 모델 요청 0, 봉인 파일 레포 밖, 문장 겹침 수.

## 판정 (사전 고정)
- **즉시(1차)**
  - **LINKED**: CONCEPT 해석 ≥ 0.60 **그리고** ≥ NONE + 30 pp **그리고** 행동 성공 ≥ 0.60.
  - **WEAK**: 유효한 실행이 LINKED에 미달.
  - **INVALID**: 교사 import·모델 호출이 1회라도 있거나 봉인이 깨진 경우.
- **개념의 기여(2차)**: CONCEPT − FLAT 해석 ≥ +10 pp일 때만 "내부 개념이 영어 연결에 기여했다"고 쓴다. 아니면 "원시 원자 이상의 기여는 보이지 않았다"고 쓴다.
- **지연**: 지연 세트 해석 ≥ 0.8 × 즉시 해석 **그리고** 연결 파일 sha 불변이면 **REUSED**, 아니면 **NOT_REUSED**. 지연 결과는 별도 보고서로 추가한다.
- **호칭**: 교사·Qwen을 끄고 재현된 범위만 "자체 언어 능력"이라 부른다. 그 범위는 "세 도구의 좁은 명령문 해석"이다.
- **실행 전 기대**: 평가 문장에는 훈련에 없던 표현이 많을 것이다. 그래서 **WEAK**를 예상하고, 개념의 기여는 없을 것(CONCEPT ≈ FLAT)으로 예상한다. P8에서 개념 원자와 합성 원자의 예측력이 같았기 때문이다.
