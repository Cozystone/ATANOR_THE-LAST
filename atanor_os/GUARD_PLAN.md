# 거절 조건: 세계의 조건을 "가장 적은 설명"으로만 믿기 (사전 등록)

## 배경 (`LIVE_PLAN.md` 후속, dev)
직접 사는 Self의 틀림은 대부분 되는 호출을 거절로 예측한 것이다. 자기 시도 몇 번에서 조건을 고르면 후보가 수백 개라 우연히 맞는
조건이 생긴다. 세계의 조건을 기억에서 가져와 거절 1번으로 다 믿게 하면 틀림이 오히려 늘었다.

## 방법 (`memory/live.py` CONDS, `memory/guards.py`)
- 기억: 앞쪽 도구마다, 성공에서 한 번도 참이 아니면서 거절을 덮는 조건(한 속성의 값, 수의 경계, 두 속성 비교, 그리고 단독으로는
  안 되는 두 조건의 결합) 중 거절 3번 이상에서 참인 것을, 인자 위치를 뗀 형태로 둔다. 앞쪽 도구 2개 이상에 있는 조건만 후보다.
- 새 도구: 후보를 그 도구에 놓고, 자기 성공에서 참이었던 것은 버린다. 남은 것 중 **자기가 겪은 거절을 설명하는 가장 적은 수**만
  믿는다(더 많은 앞쪽 도구에 있던 것 우선). 나머지 후보가 참인 시작은 "모름"이다. 모르는 시작을 먼저 해보므로 스스로 시험하게 된다.
- 기억으로 설명되지 않는 거절은 전과 같이 자기 조건(3번 확인)으로 덮는다.
세계의 낱말·규칙은 코어에 없다.

## 최종 평가 (한 번): a, b, c의 세계 시드 140–143 (연 적 없음), 시도 8, 20, 세 저자 합

- R2: 8번과 20번 모두 NEW 틀림 수 ≤ 0.9 × OLD 틀림 수.
- R3: 20번에서 NEW 틀림 수 ≤ NONE 틀림 수 (과거가 있는 쪽이 더 틀린다는 `LIVE_PLAN.md`의 약점이 없어지는가).
