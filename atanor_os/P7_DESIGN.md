# P7 — 언어 모델을 지각 도구로 둔 자율 과제 단계 (설계, 2026-10-24)

## 결정과 경계 (사용자)
- 방향 (b): 자유로운 영어 읽기는 현 단계에서 **언어 모델을 명시적인 지각 도구로** 쓴다.
- **모델 호출 인터페이스는 하나뿐이다.** ATANOR가 고른 원문 일부를 넘기면, 모델은 **출처 인용이 붙은 사실 후보**만 돌려준다.
- 모델에 맡기지 않는 일: 목표 분해·해석, 검색 계획, 방문할 출처 선택, 신뢰 판정, 보류·행동 선택, 자기 코드 변경.
- 모든 호출을 기록한다. 기록 항목: 모델 이름과 digest, 고정 프롬프트 판본, 원문 조각의 sha256과 길이, 응답, 지연 시간, 인용 검증 결과.
- **모델을 끈 성능을 함께 보고한다.** "ATANOR가 배웠다"는 주장은 모델 없이 재현된 능력에만 붙인다. 모델이 읽어 준 성과는 ATANOR의 영어 능력으로 세지 않는다.
- 모델 제거는 정해진 일정으로 하지 않는다. 교사를 끈 후속 시험에서 그 능력이 실제로 대체되었을 때 결정한다. 그전까지는 제거를 전제로 설계를 비틀지 않는다.

## 구조
| 층 | 누가 | 내용 |
|---|---|---|
| 목표 해석 | ATANOR | 학습된 어휘(P6/H6). 모델 사용 금지 |
| 정보 필요 판단 | ATANOR | 파일마다 필요한 사실(형식의 공식 명칭)이 기억에 있는지, 이미 실패했는지 판단 |
| 검색·방문 선택 | ATANOR | 학습된 질의·서비스 효용, 결과 관련성 모델, 호스트 효용 |
| 원문 조각 선택 | ATANOR | 확장자가 언급된 곳 주변 창과 문서 첫 문단. 길이 상한이 있으며, 어느 조각을 넘길지 ATANOR 코드가 정한다 |
| **사실 후보 추출** | **언어 모델(지각)** | 고정 프롬프트: "이 조각이 확장자 .X를 쓰는 파일 형식의 이름으로 말하는 후보를, 조각 안의 그대로 인용과 함께 JSON으로" |
| 인용 검증 | ATANOR | 인용이 조각 안에 글자 그대로 있는지, 후보값이 인용 안에 있는지 확인. 하나라도 아니면 그 후보를 버린다 |
| 근거 대조·신뢰 | ATANOR | 서로 다른 페이지 2곳 이상이 일치하면 채택(P6와 같은 규칙, 모델 사용·미사용 조건이 같은 규칙을 쓴다). 모순·단일 출처·근거 없음이면 그 파일을 둔다(모델 점수는 쓰지 않음) |
| 행동·검증 | ATANOR | 샌드박스 리허설 → 학습된 파일 규칙으로 실행 → 재관측 |

모델 접근은 `agent/perception.py` 한 곳에서만 한다. 다른 모듈이 로컬 모델 포트나 LLM 엔드포인트에 닿는 코드를 담으면 테스트가 실패한다. 웹 몸은 계속 localhost와 LLM 호스트를 막는다.

## 측정 (모델 사용 / 미사용을 모두)
1. **정보 필요 판단**: 트리거 타당성(이미 아는 사실을 다시 찾지 않음, 모르는 사실은 찾음), 미지 항목 탐지.
2. **검색·방문 선택**: 관련 페이지를 연 형식의 비율(1개 이상 / 2개 이상), 사실 하나당 요청 수.
3. **근거 대조**: 모델 후보를 받은 뒤 ATANOR의 채택 정밀도·재현율. 모순·단일 출처를 처리한 방식. 인용 검증에서 버린 후보 수.
4. **보류·행동 결정**: 잘못 놓은 파일, 불가능 과제의 올바른 멈춤. 이번에는 F+모델이 가능 과제의 이름을 찾을 수 있으므로 "모를 때 멈춤"을 구별해서 잴 수 있다.
5. **결과 검증**: 리허설 결과와 실제 결과가 일치하는지, 평가기의 재관측 판정.
6. 과제 완수: F+모델, F−모델(ATANOR 자체 읽기), ORACLE, N.
7. 모델 비용: 호출 수, 토큰 또는 문자 수, 지연 시간, 인용 검증 거부율.

"학습"으로 셀 수 있는 것은 F−모델에서도 재현되는 항목뿐이다(1·2·4·5의 정책 부분). 3과 6의 F+모델 성과는 "지각 도구를 쓴 결과"로만 보고한다.

## 평가 분리
- 새 평가 형식: 훈련·H6 전이에 쓰지 않은 Wikidata 형식에서, 동결 공개 커밋 해시를 seed로 추첨한다.
- 새 평가 문장: 교사 문맥이 없는 에이전트가 레포 밖에 쓰고, 실행 전에는 해시만 공개한다.
- 평가는 1회 실행하고, 교사 호출은 0이어야 한다.
