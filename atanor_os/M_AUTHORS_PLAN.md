# M단계: 여러 저자의 세계로 배우면, 본 적 없는 저자의 세계로 건너가는가 (2026-11-10, 생성기를 보기 전에 고정)

## 왜

다른 가족으로의 전이 시도 셋(H +0.53, K +2.48, L +1.76%p)이 모두 실패했다. K에서 학습 가족을 넓히자 읽기 단독이 크게 좋아졌다. 문헌(Seth 등 2026)도 과제 다양성이 새 과제의 출발점을 좋게 한다고 말한다. 지금까지의 학습 세계는 모두 **한 저자(나)**의 문법이었다. 저자의 버릇을 넘어서는지를 직접 잰다.

## 설계

- **저자 다섯:** 별도 에이전트 다섯이 서로의 파일과 이 저장소를 읽지 않고 세계 가족 생성기를 쓴다(`families/fam_a.py` … `fam_e.py`, 저장소 밖). 주제: 사무 소프트웨어 / 기계·장치 / 게임·스포츠 / 자연·실험실 / 공공 서비스·교통·거래. 이 세션은 생성기 코드를 읽지 않고 `world(seed)`만 부른다.
- **저자 하나 빼기(leave-one-author-out):** 넷의 세계(시드 0–599)로 학습(`meta-k1`에서 시작, 6,000걸음, 성공 예시 절반), 남은 저자의 세계(시드 5000–5099, 어느 학습에도 없음)에서 잰다.
- **조건:** EMPTY(기호 마음), HYBRID(기호 마음의 모름에만 읽기 모형, τ0.95, 표결 1, k=10 — K에서 고정한 그대로, 바꾸지 않음), READER(읽기 단독, τ0). 비교 기준선: `meta-k1`(내 문법만)으로 같은 시험.
- 저자마다 설정을 바꾸지 않는다. 결과를 본 뒤 τ나 학습을 고치지 않는다.

## 기준

| 기준 | 내용 |
|---|---|
| M1 건너감 | 다섯 저자 중 넷 이상에서, 넷으로 배운 혼성의 정답이 기호 마음보다 3%p 이상 높고 틀림 증가 ≤ 1%p |
| M2 다양성 | 다섯 저자 중 넷 이상에서, 넷으로 배운 읽기 단독의 정답이 `meta-k1` 읽기 단독보다 높다 |

- **통과:** M1·M2. **부분:** 하나만. **실패:** 둘 다 아님.

## 한계

- 저자는 모두 같은 모델 계열의 에이전트다. 사람 저자의 다양성은 아니다.
- 학습 자료는 ATANOR의 삶이 아니다.
- 생성기 품질은 저자의 자체 점검에만 의존한다.

- M1: a–e 모두 +3%p 이상, 틀림 증가 ≤ 1%p. M2: a–e 모두 읽기 단독이 k1보다 높음(+3.9 ~ +11.0점). **통과.**
- 다양성의 몫: 같은 τ에서 k1 혼성 이득은 +3.6 ~ +4.5%p, 넷으로 배운 혼성은 +7.9 ~ +14.9%p(e +10.8). 틀림도 k1보다 적다.
- 한계(그대로): 저자는 같은 모델 계열의 에이전트다. 학습 자료는 ATANOR의 삶이 아니다. 이것은 기억 기관 하나의 측정이며 삶의 평가가 아니다.

## M3 대조 (결과를 본 뒤 추가, 사후 대조로 기록, 실행 전에 고정)

M2의 비교 대상 k1은 추가 학습을 받지 않았다. 넷으로 배운 모형의 우위가 저자 다양성 때문인지, 남의 문법으로 6,000걸음 더 배운 것 때문인지 가른다.

- **한 저자 대조:** 빼낸 저자 X마다, 미리 정한 한 저자(a→b, b→c, c→d, d→e, e→a의 다음 글자)의 세계 시드 0–2399(넷 × 600과 같은 세계 수)로 `meta-k1`에서 6,000걸음, 나머지 설정은 같게 학습. X의 시드 5000–5099에서 같은 시험.
- **M3 기준:** 다섯 중 넷 이상에서 넷으로 배운 읽기 단독 정답이 한 저자 대조보다 높다. 혼성도 함께 적는다.
- 통과하면 몫은 다양성이다. 실패하면 몫은 "다른 저자의 세계로 더 배운 것"으로 고쳐 적는다(M1은 그대로 유효).

### M3 결과 — **실패 (2/5)**

| 빼낸 저자 | 읽기 단독: 넷 / 한 저자 | 혼성: 넷 R / W | 혼성: 한 저자 R / W |
|---|---|---|---|
| a (한 저자 b) | .700 / .675 | .535 / .0106 | .512 / .0102 |
| b (c) | .648 / .660 | .501 / .0204 | .521 / .0215 |
| c (d) | .721 / .724 | .506 / .0105 | .535 / .0114 |
| d (e) | .717 / .723 | .546 / .0125 | .566 / .0144 |
| e (a) | .693 / .686 | .491 / .0096 | .470 / .0111 |

- 같은 세계 수와 걸음이면 **다른 저자 한 명**으로 배워도 넷과 거의 같다(차이 −1.2 ~ +2.5점). M2의 우위는 다양성이 아니라 **내가 쓰지 않은 세계로 더 배운 것**에서 나왔다. M단계의 "몫은 저자 다양성" 해석을 이것으로 고친다.
- M1(본 적 없는 저자로 건너감)은 그대로 유효하다. 다만 저자들은 모두 내가 준 같은 명세(`world(seed)` → 과정·질의)로 썼으므로, 저자들의 세계끼리가 내 문법과 봉인 세계보다 서로 가까울 수 있다. 실제 몸에서 확인해야 한다.
