## 1. 모델과 경계
- **모델**: `qwen2.5:7b-instruct`, Ollama 0.40.3, digest `845dbda0ea48ed749caafd9e6037047aa19acfcfd82e704d7ca97d631a0b697e`, 7.6B 파라미터, Q4_K_M, Apache-2.0. temperature 0, seed 7, 프롬프트 판본 `p7-extract-v1`.
- **모델이 하는 일은 한 가지다**: ATANOR가 고른 원문 조각에서 "확장자 .X를 쓰는 형식의 이름" 후보를 그대로 옮긴 인용과 함께 내놓는다.
- **ATANOR가 하는 일**: 인용이 조각 안에 글자 그대로 있는지 확인하고, 아니면 그 후보를 버린다. 목표 해석, 검색, 방문, 대조(두 페이지 일치), 보류·행동, 결과 검증도 모두 ATANOR 코드가 한다.
- **목표 문장은 모델에 전달하지 않는다**(테스트로 확인).

## 3. ATANOR의 결정 능력 — 성과의 주체를 나눠서
**모델 없이도 재현된 것(ATANOR 자신의 능력으로 셀 수 있는 것)**
- **목표 해석**: 처음 보는 봉인 문장 36개 중 33개(0.92)를 맞혔다. P6에서 0.67이던 값이 H6-1의 교사 단서 표시와 대조 문장으로 올랐다. 모델은 해석에 관여하지 않는다.
- **정보 필요 판단**: 이미 아는 사실을 다시 찾은 경우 0, 실패한 사실을 다시 찾은 경우 0이었다(실패 기억).
- **멈춤**: 불가능 과제 6/6에서 근거 없음으로 멈췄고, 잘못 놓은 파일도 0이다. 단, 모델을 끈 F는 모든 파일에서 멈췄다. 따라서 이 멈춤은 "구별해서 멈춘다"의 증거가 아니다.

**모델(읽기 도구)과 함께일 때 드러난 ATANOR의 결정층**
- **근거 대조의 가치가 실측됐다**: 같은 모델 후보로 S_LM(첫 출처 채택)은 형식 14개를 틀리게 채택해 과제당 1.44개 파일을 잘못 놓았다. F_LM(두 페이지 일치를 요구하는 ATANOR 규칙)은 틀린 채택 1개, 과제당 0.17개였다. 대신 F_LM은 맞게 채택한 수도 적다(4 대 7). 이 규칙은 정밀도와 재현율을 맞바꾼다.
- **보류 판단**: F_LM은 파일 108개 중 44개를 단일 출처, 13개를 모순, 33개를 근거 없음으로 두고 이유를 남겼다.
- **결과 검증**: 샌드박스 리허설 17회는 모두 성공했고, 실제 행동 18회도 모두 재관측에서 성공으로 확인됐다. 리허설과 실제 결과가 어긋난 사례는 0이다.

## 4. 실패 지점
1. **과제 완수 0의 직접 원인은 재현율이다.** 과제를 완수하려면 파일 3개가 모두 맞아야 한다. 그런데 F_LM이 맞게 채택한 형식은 31개 중 4개였다.
   - 모델이 내놓은 후보의 64%(124개 중 80개)가 인용 검증에서 거부됐다. 조각에 없는 문장을 인용으로 내놓은 것이다.
   - 수락된 후보도 두 번째로 일치하는 페이지가 없어 단일 출처로 멈춘 경우가 많았다(44건).
2. **페이지가 하나뿐인 형식이 많다.** 이번 평가 형식 상당수는 영어 위키백과 문서는 있지만 같은 이름을 확인해 줄 두 번째 페이지를 검색 진입점(Wikimedia·Wiby)으로 찾기 어려웠다. 이 결과는 열린 인터넷 전반을 탐색한 결과가 아니다.
3. **진실 레이블의 특이함.** 단일 레이블 규칙으로 고른 Wikidata 레이블 가운데 일부는 문서의 일반 명칭과 다르다.

   | 확장자 | Wikidata 정답 | 읽어 낸 이름 |
   |---|---|---|
   | `gif` | "animated GIF" | "Graphics Interchange Format" |
   | `ini` | "INI file" | — |
   | `prc` | "Product Representation Compact" | "PRC (Product Representation Compact)" |

   사전등록 판정대로 모두 오답으로 셌다. 판정 기준을 사후에 바꾸지 않는다.
4. 사용자 지시에 따라 **모델의 역할을 넓혀 재시험하지 않았다.** 예를 들어 모델에게 출처를 고르게 하거나 신뢰를 판정하게 하지 않았다.

## 5. 주장할 수 있는 것 / 없는 것
- **있다**: ATANOR의 목표 해석이 처음 보는 표현에서 0.92가 됐다(모델 없음). 두 출처 대조 규칙이 같은 지각 입력에서 잘못 놓은 파일을 1.44에서 0.17/과제로 줄였다. 리허설과 실제 결과가 일치했다.
- **없다**: ATANOR가 영어를 읽는다는 것(모델 없이 F는 채택 0). 낯선 일을 스스로 끝까지 해낸다는 것(과제 완수 0). 열린 인터넷 전반을 탐색했다는 것.
- 모델 제거 여부: 읽기를 대체할 ATANOR 자체 능력이 시험에서 확인되지 않았으므로 지금은 판단 대상이 아니다.
