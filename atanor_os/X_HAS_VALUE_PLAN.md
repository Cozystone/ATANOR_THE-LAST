# X단계: "이 속성에 값이 있음"이라는 기준 (2026-11-11, 새 시드 전에 고정)

## 왜

Claude가 가르친 세션(출처 `claude`)에서 틀림 1건의 원인: "바구니에 든 memo 카드"를 가르쳤는데, 선택 기준은 `속성=특정 값`만 표현하므로 "어느 바구니든 들어 있음"을 담을 수 없었다. 가리킨 두 카드가 같은 바구니면 "그 바구니"로, 다른 바구니면 "memo"로만 배운다.

## 변경 (`agent/concepts.py`, 스위치 `ATANOR_HAS_ATOMS=1`)

속성에 값이 있으면(없음 `-`이 아니면) 기준 원자 `('H', 속성)`을 하나 더 만든다. 학습기가 쓰는 가설 공간이 넓어질 뿐, 답이나 낱말을 넣는 것이 아니다.

## 개발

- 두 조건 과제(`ui/two_condition.py`, 보드 시드 1–5 중 해당되는 2개): "어떤 표시이고 바구니에 든 카드"를 서로 다른 바구니의 두 장으로 가르친 뒤, 다음 세션에서 함께 가르친 적 없는 행동과 조합해 명령. 기준 없음 0/2, 기준 있음 2/2.
- 대본 교사 회귀(시드 1–3, 실수 0): 명령 성공 129/132 → 125/132, 보류 3 → 6, 틀림 0 → 1. 대본 교사의 개념에는 이 기준이 필요 없으므로 넓어진 가설 공간의 비용이다.
