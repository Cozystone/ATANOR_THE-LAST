# H단계: 자기 경험만으로 배우는 관계 세계 모형 (2026-11-09, 코드를 짜기 전에 고정)

## 창립자 결정 (2026-11-09 밤)

"외부 LLM·sLLM을 런타임에 쓰지 않는다"는 금지는 유지한다. 그러나 이 금지는 **표현 학습 자체의 금지가 아니다.** ATANOR가 **자기 경험만으로**(사람의 글 0줄, 외부 모델 0개) 학습한 작은 신경망은 ATANOR의 기관이다. 창립자: "그렇게 결정할게. 가장 잘 되는 방향으로 알아서 가줘."

근거: 기호 코어 위에서 몸을 건너는 능력을 만들려는 시도 7회(사전 확률 3, 역할 공간 1, 생존 선택 4판)가 모두 실패했다(`cbd25d0a`, `G_SURVIVAL_PLAN.md`). 공통 원인은 표현을 개발자가 정하고 기억을 몸의 낱말로 저장하는 것이다. 문헌(`reports/전이 복리 최신 연구 조사.md`)과 뇌과학 조사가 가리키는 자리는 "구조와 내용의 분리"이고, 그것은 손으로 짜는 것이 아니라 학습으로 나와야 한다.

## 역할 분담 (무엇이 바뀌고 무엇이 남는가)

- **남는 것:** 하나의 Self, 자서전(SHA 사슬), 여섯 몸, 교사, 판정법(빈 마음 vs 산 마음 vs 대조군), 읽음/겪음 구분, 에너지와 죽음, 행동 안전(확신 없으면 안 함, 틀림 ≤ 1%).
- **바뀌는 것:** 효과 예측 기관. 몸마다 따로 있던 표(`rebuild/effects.py`) 옆에 **하나의 학습된 모형**이 들어온다. 모든 몸의 경험이 한 모형에 들어간다.
- **금지 유지:** 사람이 쓴 글, 사전 학습 가중치, 외부 API는 들어가지 않는다. 몸의 정답·규칙·영어 낱말은 들어가지 않는다. 학습 자료는 ATANOR의 경험 저장소뿐이다.

## 모형

입력은 행동(도구 이름, 인자 수)과 인자 대상들의 관측(속성 이름 → 값)이다. 핵심은 **낱말을 이름으로 쓰지 않는 부호화**다. 대상의 속성 하나는 다음으로 표현된다.

1. **관계 특징(낱말 없음):** 값이 비었는가('-'), 같은 대상의 다른 속성과 같은가, 다른 인자의 어느 속성과 같은가, 이 행동의 과거 사례에서 그 속성이 변한 적 있는가, 이 값이 이 행동에서 처음 보는 값인가.
2. **낱말 임베딩(해시):** 속성 이름과 값의 문자열을 해시해 작은 임베딩으로. 같은 몸 안에서는 쓸모가 있고, 새 몸에서는 거의 무작위다. **이 둘의 비중을 모형이 배운다.** 낱말이 바뀐 몸에서도 맞히면 관계 특징을 배운 것이다.

구조: 인자 대상 집합 → 속성 토큰 집합 → 집합 주의(attention) 2~3층 → 출력은 속성마다 {그대로, 비움, 다른 인자의 어느 속성 값 복사, 보던 값 중 하나} + 응답 {ok, failed, blocked}. 크기는 100만 매개변수 안쪽. 외부 자료 없음.

**기권:** 출력 확률이 τ 미만이면 '모름'. 행동은 모르는 것을 하지 않는다(지금 규칙 그대로).

## 측정 (개발 시드 1–5에서 개발, 최종은 새 시드와 새 몸)

- **자료:** 여섯 몸 과정 경험(교사 시범·명령) + 연습 시도. 질의는 지금 벤치의 평가 세계 질의(`stage1-dev/cache`).
- **전이 시험:** 다섯 몸으로 학습 → 여섯째 몸(학습에 없던 몸).
  - **0샷:** 여섯째 몸의 경험 없이 질의.
  - **k샷:** 여섯째 몸의 과정 경험 k개(1, 3, 10, 30)만 더해 미세 조정.
  - **낱말 치환 대조:** 여섯째 몸의 낱말을 전부 바꿔도(암호 치환) 같은 정답률이면 구조를 배운 것이다.
- **기준선 둘:** (a) 빈 마음 = 지금의 기호 예측기, 여섯째 몸 과정만(과거 없음). (b) 같은 모형을 다섯 몸 없이 여섯째 몸 k샷만으로.
- 여섯 몸 모두를 한 번씩 여섯째 몸으로 둔다(leave-one-body-out).

## 기준 (미리 고정)

| 기준 | 내용 |
|---|---|
| H1 복리 | k샷 정답률이 (b)보다 높고 빈 마음(a)보다 높은 몸이 여섯 중 넷 이상, k ∈ {3, 10}에서. |
| H2 안전 | 기권을 포함한 틀림률 ≤ 1% (τ를 미리 정해 두고 바꾸지 않음; 개발에서 정함). |
| H3 구조 | 낱말 치환 뒤 정답률 하락이 10점 이내인 몸이 넷 이상. |

- **통과:** H1·H2·H3. **부분:** H1·H2. **실패:** H1 불성립.
- 실패하면 원인을 자료 양 / 부호화 / 모형 크기 / 세계의 공유 구조 부족 중 하나로 분류하고, "세계의 공유 구조 부족"이면 몸 생성기를 만드는 쪽으로 간다.

## 한계 (미리 적음)

- 몸 여섯 개, 속성 다섯 개는 신경망을 학습하기엔 작다. 자료 부족이면 그렇게 적는다. 다음은 몸 자동 생성이다.
- 대상의 경계와 속성의 경계는 여전히 어댑터가 준다(D단계 미완). 이 모형은 "속성 안의 값과 관계"를 배우지 "속성이 무엇인가"를 배우지 않는다.
- 교사가 프로그램이다. 사람 결과와 섞지 않는다.
- 이 모형이 맞혀도 "이해"나 "의식"을 말하지 않는다.
- GPU 하나(RTX 5080). 학습은 분 단위여야 한다.

## 실행 기록

1. **1차 (2026-11-10, 시드 1–5, 염색·온도 처음 만남, 기권 없음, 전체 결과 일치 채점):** 빈 기호 마음 정답률 염색 .518 / 온도 .694 (틀림 .008 / 0). 학습 모형은 새 몸에서 거의 0이었다. 염색 LIFE 0샷 .004, 3샷 .111, 10샷 .032, 30샷 .028; 암호 치환 3샷 .174; 혼자 배운 모형(ALONE) 3·10·30샷 모두 .000. 온도는 LIFE 3샷 .032, 나머지 ≤ .037. 다섯 몸의 자기 자료는 396/400을 맞힌다. **정정(2026-11-10):** 이 실행의 LIFE는 실행기 버그로 다섯 몸이 아니라 **다른 한 몸**(염색에는 온도, 온도에는 염색)만 배운 모형이었다. 수치는 그대로 두되 '다섯 몸 학습' 결과로 읽지 않는다. **판단:** 미세 조정으로 새 몸의 낱말을 배우는 방식은 이 자료 규모(몸당 과정 100~480개)에서 기호 예측기에 크게 진다. 30샷이 3샷보다 낮은 것은 미세 조정이 불안정해서다(학습률·epoch). 보드·책상·파일·뷰 실행은 세션 종료로 끊겼다. 다음은 측정을 토큰 단위로도 보고, **미세 조정 대신 맥락 안 학습**(새 몸의 k개 경험을 같은 입력에 넣어 가중치 갱신 없이 쓰는 에피소드 학습)으로 간다. 그래야 "배우는 법을 배웠는가"를 직접 잰다.
2. **2차 진단 (2026-11-10, 염색 처음 만남, 다섯 몸 학습 확인, 시드 1–5 질의 1095, 기권 없음):** 미세 조정을 충분히(200 epoch) 하면 결과가 달라진다. 30샷: 다섯 몸을 배운 뒤 미세 조정 **.429** vs 염색 30샷만 배운 모형 **.377** (토큰 정확도 .886 vs .900, 응답 정확도 .562 vs .498). 염색 과정 전부(575)로 배우면 .634(기호 마음 .518, 단 틀림 .366). 토큰 단위로는 장면의 89~95%가 맞고, 틀린 장면 대부분은 토큰 한 개가 틀렸다. **읽기:** 다섯 몸의 삶이 새 몸 30샷에서 +5점을 줬다. 작고(한 몸, 개발 시드), 기권 없이 잰 것이며, 응답(ok/failed) 머리가 약하다. 처음으로 몸을 건너는 양의 신호이나 결과가 아니다. 다음 실행은 맥락 안 학습(에피소드) 모형, 여섯 몸 전부.
3. **3차 (2026-11-10, 맥락 안 학습, 가중치 갱신 없음, 시드 1–5):** (가) 암호 없이 학습: 자기 몸으로 배운 모형은 염색 1샷 .720 / 온도 .600(틀림 28~40%). 다섯 몸으로 배운 모형은 새 몸에서 .005~.076. 낱말을 외운 것. (나) 에피소드마다 낱말 암호 강제: 새 몸 염색 .066/.025/.006(1/3/10샷), 온도 .066/.015/.001 — 예시가 많을수록 나빠짐. 진단: **학습한 몸에 새 낱말을 넣으면 .688(복사 495/561, 새 값 160/160)로 구조를 읽지만, 새 몸에서는 복사 0/214, 새 값 0/800.** 원인 하나는 설계 결함이다: 새 값의 출력이 '낱말 해시 통'이어서 암호 학습 아래 배울 수 없었다. 고침: 답이 에피소드의 **어느 토큰이든**(예시의 결과 상태 포함) 가리킬 수 있게 했다. 재측정 중.
