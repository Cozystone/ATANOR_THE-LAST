# 네 번째 몸: 데스크 (로컬 사무 작업 공간 sandbox) — 설계 (구현 전, 2026-10-27)

## 목적
기존 보드·파일·화면의 변형이 아니다. 관측·도구·실패 양식이 구조적으로 다른, 제한된 로컬 디지털 세계를 하나 더한다. ATANOR는 이 몸에서도 같은 계약만 쓴다. 가리키기, 대조 질문, 시범, 확인, 기호 뒤 구절, 혼자 행동, 바뀐 뒤 실험으로 회복, 모르면 멈춤이다.

## 세계 (관측)
sandbox 폴더 안의 JSON 상태 하나에, 네 '앱'의 항목이 함께 있다.

| 항목 종류 | 앱 | 상태 값 |
|---|---|---|
| message | 받은편지함 (`inbox`) / 보관 (`archive`) | `unread`, `read`, `locked` |
| draft | 보낼 편지 (`outbox`) | `draft`, `queued`, `sent`, `failed` |
| task | 할 일 (`tasks`) | `open`, `done`, `blocked` |
| note | 메모 (`notes`) | `plain`, `pinned` |

항목마다 꼬리표(`tag`: `none`, `red`, `blue`, `green`)가 있다. 꼬리표, 위치(앱/폴더), 상태 값은 값 대상(`t.red`, `f.archive` 같은)으로도 존재한다. 학습기는 이것을 이름 없는 원자로만 본다. 원자는 a0 종류, a1 위치, a2 상태, a3 꼬리표, a4 값이고, 관계는 없다.

## 도구 (행동)
| 도구 | 인자 | 효과 | 실패 |
|---|---|---|---|
| `read` | 메시지 | unread → read | 잠긴 메시지는 실패 |
| `file` | 항목, 위치 | 위치를 바꾼다(보관 등) | 잠긴 항목은 실패 |
| `tag` | 항목, 꼬리표 | 꼬리표를 붙인다 | – |
| `send` | 초안 | draft → queued. **결과는 나중에 온다.** 다음 시간 흐름에 sent 또는 failed가 되고, sent는 가끔 답장 메시지를 만든다 | 초안이 아니면 실패 |
| `complete` | 할 일 | open → done | blocked는 실패 |
| `pin` | 메모 | plain → pinned | – |
| `purge` | 항목 | **영구 삭제(되돌릴 수 없음)**. 권한(`destroy_items`)이 있을 때만, sandbox 안에서만 | 권한이 없으면 막힘 |

## 실패 양식 (기존 몸에 없던 것)
1. **지연 효과.** 보내기의 끝 상태는 행동 직후가 아니라 다음 시간 흐름에서 보인다.
2. **외부 상태 변화.** 세션 사이에(그리고 시간 흐름 때) 바깥 행위자가 항목을 바꾼다. 새 메시지가 오고, 일부 항목이 잠기거나 풀리고, 일부 할 일이 막힌다.
3. **부분 성공.** 한 명령이 여러 대상에 쓰일 때 잠긴 것만 실패할 수 있다. 판정은 할 수 있는 대상만 기대한다(사람도 잠긴 것은 기대하지 않는다).
4. **도구 변화.** 과정 중에는 `file`이 멈추고, 인자 순서가 반대인 새 도구 `shelve`(위치, 항목)가 생긴다. 평가에서 과정에 없던 변화로는 `tag`이 멈추고 `mark`(꼬리표, 항목)가 생긴다.

## 안전 경계
- 모든 상태는 저장소 밖 sandbox 폴더의 JSON이다. 실제 메일, 파일, 앱, 네트워크에는 닿지 않는다. 보내기는 sandbox 안의 상태만 바꾼다.
- 영구 삭제(`purge`)는 권한이 있을 때만 된다. 학습기는 몸이 알리는 권한 목록을 그대로 쓴다.
- 혼자일 때 되돌릴 수 없는 행동을 짐작으로 하지 않는 기존 규칙(전이 기제 포함)이 그대로 적용된다.

## 재생 가능한 기록
- 세계는 시드로 만들어진다. 외부 변화도 (시드, 세션, 시간 흐름 번호)로 정해진다.
- 몸은 모든 행동과 외부 변화를 `world_log.jsonl`에 남긴다(누가, 무엇을, 결과, 전후 상태 지문). 같은 시드와 같은 행동 순서면 같은 기록이 나온다.

## 코어와 학습기에 넣지 않는 것
앱, 상태, 꼬리표의 이름이나 뜻, 영어 낱말, 행동 순서, 지연 규칙은 코어와 학습기에 넣지 않는다. 몸이 주는 것은 원자 변환(`raw_obs`의 desk 부분), 도구 표, 실행, 실험실 사본, 시간 흐름(세계 쪽)뿐이다. 영어 구절표와 정답 판정은 평가기 쪽(교사 명세)에만 있다.
