# RESEARCH_CONTRACT — P1

기준 문서: ATANOR OS 개발 헌장 v0.1 (2026-10-24). 이 파일은 그 중 P1에서 구속력을 갖는 항목만 적는다.

## 고정
1. 실행 시 판단·학습·계획·코드 생성에 외부 LLM/API·로컬 sLLM을 쓰지 않는다. 개발자가 Claude로 구현한 것은 별개다.
2. 사람이 넣은 지식(BOOTSTRAP_MANIFEST)과 시스템이 획득한 것을 구분해 보고한다.
3. 저장·검색만 하는 비교군(B)보다 **새 조건**에서 나아져야 학습이다. 기록 증가는 학습이 아니다.
4. 안전장치(capability 차단)와 인지 능력을 분리 집계한다. 차단된 제안도 기록한다.
5. 학습 비용과 평가 비용을 분리 측정한다.
6. 실패는 표현/학습/검색/계획/관측/평가 중 어디서 났는지 좁힌다. 사건별 if문 금지.
7. 기존 파일·저장소·OS·USB·권한은 보존한다. 실제 개인 자료는 쓰지 않는다.
8. 판정 기준은 최종 평가 **전에** `protocol.json`에 동결한다. 결과를 본 뒤 바꾸면 새 실험으로 기록한다.
9. 평가 정답·생성 규칙·seed는 학습기에서 접근 불가(`eval/`는 `agent/`에서 import 금지).

## 고정하지 않음
- 관계 규칙 학습·제한된 탐색은 첫 후보일 뿐. 증거가 나쁘면 버린다.
- 기존 코드의 영구 INTERRUPTED, 평생 예산, 임시 폴더 강제, 정확한 타입 제한은 계승하지 않는다.
- 결정론적 환경, 보상 신호, 원시 픽셀 등은 지금 요구사항이 아니다.

## 판정 범주
INVALID / VALID_NO_GAIN / VALID_INCONCLUSIVE / VALID_BOUNDED_GAIN. 단일 seed 성공, 학습 데이터 성능, 예쁜 로그로는 PASS 없음.
VALID_BOUNDED_GAIN도 AGI·의식·무제한 자기개선의 증거가 아니다.
