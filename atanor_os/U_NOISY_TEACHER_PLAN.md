# U단계: 실수하는 교사에게서도 배우는가 — 이해한 것을 보여 주고 확인받기 (2026-11-10, 새 시드 전에 고정)

## 왜

창립자 세션 전에 사람 교사의 실수에 학습기가 버티는지 본다. 교수 화면의 대본 교사(`ui/pilot.py`, 출처 'pilot', 사람 결과 아님)에 실수(가리킬 때 뜻하지 않은 카드 하나를 섞음, 대조 질문에 거꾸로 답함)를 확률로 넣었다.

## 개발 시드 1–3, 15세션 (변경 전)

| 실수 비율 | 수업 확인 | 명령 성공 | 보류 | 틀림 |
|---|---|---|---|---|
| 0 | 17/18 | 129/132 (.977) | 3 | 0 |
| 0.1 | 16/25 | 112/125 (.896) | 12 | 1 |
| 0.2 | 13/27 | 59/93 (.634) | 32 | 2 |

- 원인: 실수 하나가 선택 기준을 틀어 수업이 "카드가 틀림"으로 끝난다(0.1에서 7번, 0.2에서 13번).

## 변경 (사람용 화면에서만, `agent/grounding.py` + `ui/teach_server.py`)

- 가리키기와 대조 질문으로 기준을 세운 뒤, 학습기가 **그 기준이 고르는 카드들을 보여 주고 "이 카드들을 말씀하신 건가요?"라고 묻는다.** 아니면 한 번 더 가리켜 달라고 한다. 프로그램 교사(`teach/tutor.py`)에는 이 질문이 없어 다른 평가는 바뀌지 않는다. `ATANOR_SELECTION_CHECK=0`이면 끈다.
- 개발 시드 1–3(변경 후): 0 → 129/132 그대로; 0.1 → 119/132 (.902), 수업 20/26; 0.2 → 75/100 (.750), 수업 17/25, 틀림 1. "카드가 틀림" 수업은 7 → 1, 13 → 2.
- 시도했다가 버린 것: 공통점이 없을 때도 다시 가리키게 함(개발에서 이득 없음).
