## P8 — 경험에서 내부 개념을 만들고, 재시작 뒤 처음 보는 상황에서 재사용하는가

### 질문
ATANOR가 오늘의 긴 경험 기록을 **제한된 크기의 내부 표현**(개념 사전 + 그 개념으로 쓴 행동 규칙)으로 남긴다. 그리고 프로세스를 다시 시작한 뒤 **기록 없이 그 표현만으로** 처음 보는 상황에서 더 잘 예측하고 행동하는가?

### 경험
- 2026-10-24 하루 동안 기록된 탐색 경험 22,500건이다(파일 몸 13,500건, 화면 몸 9,000건).
- 같은 seed를 쓴 반복 실행이 겹치므로 (도구, 인자 역할 서명, 결과) 기준으로 중복을 제거한다.
- 시간 순서대로 앞 절반 E1과 뒤 절반 E2로 나눈다.

### 원시 관측 (사람이 준 것, 의미 이름은 지움)
"kind", "parent_kind", "same_content" 같은 사람의 개념 이름과 파생 속성은 주지 않는다. 관측 어댑터가 각 몸의 관측을 **익명 속성과 익명 관계**로 바꾼다.

| 몸 | 익명 속성 | 익명 관계 |
|---|---|---|
| 파일 | `a0` 존재 여부(0/1), `a1` 디렉터리 여부(0/1), `a2` 이름 끝 토큰, `a3` 내용 다이제스트(같음 비교만 의미 있음) | `r0(o, p)`: o의 id가 p의 id에서 마지막 구간을 뺀 것 — 구조적 포함. 이름은 붙이지 않는다 |
| 화면 | `a0`–`a4`(객체 종류, 필터, 정렬, 묶음, 값). 사람이 정한 값 토큰이지만 이름은 지운다 | 없음 |

계획기와 평가기의 목표는 사람의 속성으로 적혀 있다. 그래서 행동 시에는 어댑터가 원시 상태를 결정적으로 되돌려 사람 상태로 바꾼다(예: kind = a0·a1에서). 이 역변환은 지각·행동 인터페이스이며 개념 학습이 아니다.

### ATANOR의 개념 형성 (INTERNAL)
**원자(제공된 생성 규칙)** — 생성 규칙은 제공하지만, 어떤 조합이 개념이 되는지는 학습한다.
- 단항: 역할 i의 a_k = v
- 동등: 역할 i의 a_k = 역할 j의 a_m
- 구조 합성(깊이 1): "r0로 역할 i와 이어진 객체 o가 있고, o.a_k = v", 그리고 그 부정

**개념 만들기**
- 도구마다 성공과 실패의 대조로 조건을 유도한다.
- 여러 도구나 여러 규칙에 되풀이되는 원자 조합을 개념 c_n으로 사전에 올린다. 이름은 번호뿐이다.
- 규칙은 개념으로 다시 쓴다.

**크기 제한**
- 직렬화한 사전과 규칙이 B 바이트를 넘지 않게 한다.
- 넘으면 "바이트당 설명한 경험 수"가 낮은 개념이나 규칙부터 버린다.

**수정**
- E1로 만든 표현 R1에서 시작한다. E1 원본은 다시 보지 않는다.
- E2를 받으면 기존 개념을 원자로 재사용해 다시 유도한다.
- 관측된 범위에서 외연이 같아진 개념은 합치고, 반례가 나온 개념은 고친다.
- 사전의 변경(추가·합침·수정·삭제)을 기록한다.

**재시작**
- 학습 프로세스는 표현 파일 하나만 남긴다.
- 시험 프로세스는 경험 기록이 없는 빈 디렉터리에서 그 파일만 읽는다. 평가기가 이를 확인한다.

### 비교군 (같은 처음 보는 상황, 같은 계획기와 예산)
| 조건 | 무엇을 보관하나 | 무엇이 다른가 |
|---|---|---|
| **INTERNAL(B)** | B 바이트 표현만 | 개념 발명 + 압축 |
| FULL-RAW | 전체 경험 기록 | 같은 원시 원자 중 단항·동등만 쓴다(구조 합성 원자와 개념 사전 없음). "기록을 다 가지고 있으면 충분한가" |
| CASE | 전체 경험 기록 | 원시 원자 집합 위의 최근접 사례 검색(다수결). "사례 검색으로 충분한가" |
| FIXED | 전체 경험 기록 | 사람이 고정한 개념(P1–P4의 들어올린 리터럴: kind, ext, parent_kind, same_content, 유형 그룹) + 학습기 v4. "사람이 정한 개념에 얼마나 다가가나" |
| INTERNAL-∞ | 크기 제한 없는 표현 | 참고용 |

### 처음 보는 상황
- **파일 몸**: test 분할 배치(처음 보는 이름, 확장자, 깊이 2의 대상)로 만든 새 작업 공간.
- **화면 몸**: test 시작 화면(p3, 패널 2개, 필터된 목록).
- 어느 쪽도 오늘의 탐색 기록에는 없다.

### 측정
1. **예측**: 처음 보는 상황에서 실제로 실행한 행동의 결과(성공·실패와 바뀐 속성)를 맞혔는가. 도구 × 실제 결과 셀마다 20건 이상, 성공 조건과 하나만 다른 실패도 포함해 표본을 고르게 뽑는다. 정확도와 fp/fn/효과 오류를 본다.
2. **행동**: P1 파일 test 과제(20개 × seed 3)와 화면 test 과제(20개)의 엄격 완수율.
3. **크기**: 표현 바이트, 사전의 개념 수.
4. **재사용**: 두 도구 이상, 또는 두 몸에서 쓰인 개념의 수.
5. **수정**: R1 → R2 사이의 사전 변경, E2를 받은 뒤 예측·행동 정확도의 변화.
6. **비용**: 학습 시간, 시험 시간.

### 판정 (사전 고정)
**USEFUL_CONCEPTS**는 아래 다섯 조건을 모두 충족할 때만 준다.
1. INTERNAL(8 KB)의 파일 몸 예측 정확도 ≥ FULL-RAW + 5 pp **그리고** ≥ CASE + 5 pp
2. 파일·화면 과제 완수율이 둘 다 FULL-RAW 이상, CASE 이상
3. 두 도구 이상에 쓰인 발명 개념이 1개 이상
4. R1 → R2에서 사전이 1번 이상 바뀌었고, 예측 정확도가 2 pp 넘게 떨어지지 않음
5. 표현이 실제로 B 이하이고, 시험 프로세스가 기록 없이 돌았음

판정 범주:

| 범주 | 조건 |
|---|---|
| **WEAK** | INTERNAL(8 KB)의 예측이 FULL-RAW 이하이거나 CASE 이하 |
| **INCONCLUSIVE** | 그 외 |
| **INVALID** | 시험 프로세스가 경험 기록에 접근함, 표현이 B를 넘음, 처음 보는 상황이 학습 기록과 겹침 |

FIXED와의 차이는 보고만 하고 판정에는 쓰지 않는다.

**판정이 USEFUL_CONCEPTS여도 주장하지 않는 것**
- "언어가 생겼다", "의식", "자기 문법"
- USEFUL_CONCEPTS는 "제한된 크기의 자기 개념이 기록 보관이나 사례 검색보다 처음 보는 상황의 예측·행동에 더 쓸모 있었다"까지만 뜻한다.

### 알려진 한계
- 원시 관측의 속성과 관계 자체는 사람이 고른 감각이다(지각).
- 원자 생성 규칙(깊이 1 합성)은 제공한 것이다.
- 경험은 탐색 정책이 모은 것이다.
- 개념은 이 두 몸의 도구 범위 안의 개념이다.

## P9 — 내부 개념과 영어의 연결 (P8 뒤에 따로 사전등록)

**목표**: ATANOR의 내부 개념(P8의 c_n과 행동 규칙)과 영어 표현을 잇는다.

**훈련**: Claude나 Qwen이 교사가 될 수 있다. 교사는 상황·행동에 영어 설명을 붙이거나, 뜻을 설명하거나, 반례를 준다. 그래도 매번 ATANOR가 먼저 해석하고 행동한 뒤 피드백을 받는다. 연결은 ATANOR 쪽 통계(단어 ↔ 개념 공기, 행동 결과로 검증)로 학습한다.

**평가**: 교사와 Qwen을 모두 끈다. 처음 보는 영어 표현, 대상, 상황을 쓰고, 평가 문장 원본은 레포 밖에 두고 해시만 사전 공개한다.

**따로 보고하는 세 점수**
1. 문장 해석 점수: 구조화 해석이 맞았는가
2. 실제 행동 성공률: 그 해석으로 행동한 결과가 맞았는가
3. **며칠 뒤 재사용률**: 저장한 표현으로, 같은 종류의 처음 보는 문장에 3일 이상 지난 뒤 다시 시험한 결과. 실제 시간 지연을 둔다.

**호칭**: ATANOR 단독(교사·Qwen 끔)으로 재현된 범위만 "자체 언어 능력"이라고 부른다.

**명명 정답의 모호함**: `EVALUATION_POLICY.md`의 원칙을 평가 전에 적용한다.
