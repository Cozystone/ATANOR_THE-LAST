# 2세대 표현 재설계 R1 — 행동 효과를 '관측된 전이'로 담는다 (구현 전에 고정, 2026-10-27)

가설 3·4가 기각된 뒤(`GENERATION_2_STATUS.md` '멈춤'), 코어 규칙을 더하는 대신 표현을 다시 설계한다. 근거는 지금 코어(g44)의 기후실 보류를 나눠 본 결과다(시드 281–283, 진단).
- 영어 'unresolved' 84건이 가장 크다.
- 원인: 같은 영어 구절이 여러 행동 노드에 붙어 있다. 'cool down'은 과정마다 노드 2–4개, 'warm up'은 2–4개다.
- 학습기는 효과를 '시범에서 본 결과 값'으로 저장한다. 그래서 다른 단계의 칸에서 한 시범이 같은 행동인데도 새 행동이 된다(chill→frost와 mild→chill은 결과 값이 다르다).
- 같은 구절의 읽기들이 서로 다른 결과를 내니, 묶여서 보류된다.

## 재설계 하나
**행동은 '같은 도구, 같은 인자 역할(상수 포함), 같은 속성을 바꾸는 것'이다. 시범마다 결과 값이 달라도 같은 행동이며, 효과 주장에는 관측된 전이(이전 값 → 결과 값)를 모은다.**
- 결과 값이 둘 이상 관측된 행동(상대 효과)에서 대상의 '이미 됨'은 결과 값만으로 정하지 않는다. 명령마다 한 단계를 행한다.
- 도구가 바뀐 뒤 실험에서는 관측된 전이 가운데 하나가 일어났는지로 확인한다.
- 이전 상태 근거(가설 2)에는 모은 전이의 이전 값도 넣는다. 이 값들은 모두 사람의 시범에서 나온 것이다.
- 관측된 원자만 쓴다. 몸·낱말·속성 이름에 기대지 않는다.
- 기존 네 몸에서 결과 값이 시범마다 같은 행동에는 아무것도 바뀌지 않는다.
