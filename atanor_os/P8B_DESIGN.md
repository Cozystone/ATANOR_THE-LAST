# P8b 설계 — 새 경험을 배울 때 옛 반례를 잃지 않고, 정말 반박된 규칙은 고치는가 (2026-10-24, 사전 공개)

## 기록으로 고정해 두는 것
- P8의 판정 `INCONCLUSIVE`와 R1·R2 수치는 그대로 보존한다.
- P8에서 생긴 `c0`·`c2`를 "자기 언어의 탄생"으로 부르지 않는다. 이것은 **좁은 두 환경에서 생긴 유용한 익명 개념**이고, 1.9 KB 압축이라는 성과다. 합성 원자 규칙은 사람이 제공했고, 그 원자를 가진 비교군도 같은 예측력을 냈다.

## 질문
ATANOR는 새 경험을 학습할 때 두 가지를 동시에 할 수 있는가?
- **기억 보존**: 크기 제한 안에 남긴 근거로 과거의 실패 반례와 규칙 근거를 잃지 않는다.
- **낡은 지식 수정**: 세계가 실제로 바뀌어 예전에 필요했던 조건이 더 이상 필요 없으면, 그 규칙을 고친다.

## ATANOR가 하는 일 (P8b 수정)
1. **근거 저장과 선택**
   - 규칙의 조건마다, 그 조건을 지울 수 없게 만든 실패 반례의 **근거 수**를 표현 안에 남긴다.
   - 근거는 반례 전체가 아니다. "나머지 조건이 성립했는데 이 조건이 없어서 실패했다"는 압축 기록이다.
   - 크기가 B를 넘으면 무엇을 남길지 ATANOR가 고른다. 근거 가치(근거 수 × 그 규칙이 설명한 경험 수)가 낮은 근거부터 버린다.
2. **불확실 표시**
   - 저장된 근거가 부족한 조건(근거 수 < 2)은 **불확실**로 표시하고, 확정 사실처럼 쓰지 않는다.
   - 행동할 때 불확실 조건에 기대는 예측은 따로 표시한다.
3. **새 증거와의 충돌 처리**
   - 새 경험이 저장된 근거와 충돌할 수 있다. 예를 들어 저장된 조건이 없는데도 성공한 경우다.
   - ATANOR는 아래 셋 중 하나를 고른다. **"옛 조건은 절대 지우지 않는다" 같은 고정 규칙은 쓰지 않는다.**

     | 선택 | 언제 | 무엇을 하나 |
     |---|---|---|
     | **재검증** | 그 상황을 지금 세계의 시험 공간에서 직접 만들 수 있을 때 | 작은 실험을 실행한다. 결과가 성공이면 수정, 실패면 유지 |
     | **수정** | 재검증 결과가 새 증거를 확인할 때, 또는 저장된 근거가 불확실 수준일 때 | 그 조건의 근거를 은퇴시키고 규칙을 다시 유도한다 |
     | **보류** | 재검증 상황을 만들지 못했을 때 | 조건을 불확실로 표시하고 근거는 남긴다 |

   - 결정마다 기록을 남긴다(무엇, 왜, 결과).
4. **재유도**
   - 새 경험에 더해, 저장된 근거를 "합성 실패"로 함께 넣어 규칙을 다시 유도한다.
   - 그러면 새 경험에서 반례가 우연히 빠졌다는 이유만으로 조건이 사라지지 않는다.

## 시나리오
- **안정(기억 보존)**: E1로 R1을 만들고, 같은 세계의 E2로 수정한다. 옛 반례를 잃지 않아야 하고, 쓸데없이 고치면 안 된다.
- **드리프트(낡은 지식 수정)**: 세계의 도구 규칙을 실제로 바꾼 뒤 새 경험 E3을 모은다. 이 시나리오의 R1과 각 조건은 안정 시나리오를 거친 상태에서 시작한다.

  | 몸 | 바뀌는 규칙 | 이전 | 이후 |
  |---|---|---|---|
  | 파일 | `move` | 원본이 파일이어야 함 | 디렉터리도 옮길 수 있음(필요했던 조건이 사라짐) |
  | 화면 | `group` | 묶기(`grp:ext`)는 필터가 `all`일 때만 | 필터된 목록도 묶을 수 있음(필요했던 조건이 사라짐) |

- E3은 바뀐 세계에서 고정 탐색 정책으로 몸마다 600단계씩 새로 모은다. 다른 도구 규칙은 그대로다.

## 측정 (몸별로 분리)
1. **압축 크기**: 표현 바이트(B = 8 KB).
2. **예측**: 처음 보는 상황에서 실제 실행 결과를 맞히는가. 안정은 원래 세계, 드리프트는 바뀐 세계. 드리프트는 **바뀐 도구**와 **나머지 도구**를 따로 집계한다.
3. **새 과제 성공**
   - 안정: 원래 세계의 test 과제(fs 60 · view 20)
   - 드리프트: 바뀐 능력이 필요한 새 과제(fs "폴더째 보관 폴더로 옮기기" · view "필터를 유지한 채 확장자별로 묶기", 각 20)
4. **과거 과제 유지율**: R1이 풀던 test 과제 가운데 수정 후에도 푸는 비율. 안정은 원래 세계에서, 드리프트는 바뀐 세계에서 잰다(바뀐 도구에 기대지 않는 과제).
5. **결정 기록**: 수정·보류·재검증 횟수, 재검증 실험 수.
   - 안정 시나리오의 수정은 모두 "잘못된 수정"이다(세계가 바뀌지 않았으므로).
   - 드리프트 시나리오에서 바뀐 조건을 고쳤는지, 바뀌지 않은 조건을 건드리지 않았는지를 본다.

## 판정 (몸마다, 사전 고정)
**PASS(몸)** — 아래 세 묶음을 모두 충족해야 한다.
- **안정**
  - P8b 예측 ≥ R1 − 1 pp
  - 새 과제 완수 ≥ R1 − 2 pp
  - 과거 과제 유지율 ≥ 0.95
  - 잘못된 수정 ≤ 1
- **드리프트**
  - 바뀐 도구 예측 ≥ 0.90 **그리고** ≥ (R1 유지) + 20 pp
  - 나머지 도구 예측 ≥ 0.95
  - 드리프트 새 과제 완수 ≥ 0.80
  - 과거 과제 유지율 ≥ 0.95
- **공통**
  - 표현 ≤ 8 KB
  - 시험 프로세스가 경험 기록에 접근하지 않음

**전체 판정**

| 범주 | 조건 |
|---|---|
| **MEMORY_UPDATE_OK** | 두 몸 모두 PASS |
| **PARTIAL** | 한 몸만 PASS |
| **FAIL** | 두 몸 모두 실패. 원인을 분석해 확정한다 |

## P9와의 관계
P8b 결과로 "영어 연결에 쓸 내부 개념이 얼마나 안정적인가"를 몸별·개념별로 명시한다. 명시할 내용은 수정 전후 정의 동일 여부, 근거 수, 불확실 여부다. 그런 다음 P9를 사전등록하고 진행한다. P8b가 실패해도 P9를 무기한 미루지 않고, 그 안정성 한계를 P9 설계에 반영한다. P9는 평가에서 교사와 Qwen을 끈다는 원칙을 유지한다.

## 개정 1.1 (2026-10-24 23:50, 실행 전)
R1(E1로 만든 훈련 산물)과 참 모델만으로 점검했다. E2·E3 수정과 시험은 하나도 돌리지 않았다. 판정 기준은 그대로다.

1. **화면 드리프트 교체**: "필터된 목록 묶기 허용" → **"비교 화면이 이미 있어도 compare로 바꿀 수 있음"**(대상이 목록 패널이면 여전히 실패, 효과는 같음).
   - 이유: R1의 화면 `group` 규칙은 (panel, grp) 하나의 연언이고 필터 조건이 없다. 훈련 실패 11건(필터된 패널 + grp:ext)은 "필터 all 또는 값 none"을 연언 하나로 쓸 수 없어 설명되지 않은 채 남고, 그 조건의 근거도 저장되지 않는다. ATANOR가 배운 적 없는 조건을 없애면 수정 능력을 시험하지 못한다.
   - R1은 `compare`의 "대상이 비어 있음" 조건을 반례 근거 21개로 갖고 있다.
2. **화면 드리프트 과제**: 비교 화면 `cmp`가 p1을 비교하는 중이다. 한 번도 닫지 않고(`cmp`가 처음부터 끝까지 비교 화면, 닫기 권한 없음) p3을 비교하게 만든다. 바뀐 세계의 참 모델은 20/20, 원래 세계의 참 모델은 0/20을 푼다.
3. **파일 드리프트 세부**: 폴더를 자기 안으로 옮길 수는 없다. 세계가 명시적으로 거부한다(이전에는 이름 바꾸기 오류로 실패).
4. **바뀐 도구 예측 분리**
   - (a) **바뀐 상황**: 원래 규칙과 바뀐 규칙의 답이 다른 상황, 20회 이상 확인. 등록된 기준(≥ 0.90, ≥ R1 유지 + 20 pp)을 여기에 적용한다.
   - (b) **바뀐 도구의 나머지 상황**: 참 성공 20 + 참 실패 20. "나머지 도구 ≥ 0.95"에 합친다.
   - 이유: P8의 층화 표본은 바뀐 상황을 거의 뽑지 않는다. 그러면 R1이 수정 없이도 약 0.9를 받아 누구도 +20 pp를 넘을 수 없다.
   - 참 모델 점검 결과(두 몸 모두): 바뀐 세계 참 모델 (a) 1.00 / (b) 1.00, 원래 참 모델 (a) 0.00 / (b) 1.00.
5. **재검증 방식**
   - 충돌한 상황을 다시 만든다. 저장된 연언에서 그 조건을 빼고, 충돌한 새 성공의 인자 유형(첫 원시 속성)을 붙인다.
   - 지금 세계의 새 탐색 공간에서 실행한다(안정: 원래 세계, 드리프트: 바뀐 세계). 검증 1회에 최대 40블록.
   - 같은 도구의 다른 규칙이 설명하는 새 성공은 충돌로 보지 않는다.
   - 이유: 첫 판은 그 조건이 없는 아무 행동(예: 원본이 없는 경우)을 골라, 두 세계 모두에서 실패했다.
6. **세부 고정**
   - E3 = 바뀐 세계에서 explore(seed 31, 600단계, contrast-kind).
   - 예측 seed = 9100 + 10×드리프트 + 화면, 바뀐 도구 seed = 9300 + 화면(+2는 (b)).
   - R2_P8의 드리프트 = P8 수정(안정 R2, E3).
   - 전체 기록·사례·사람 개념: 안정은 E1+E2, 드리프트는 E1+E2+E3.
   - 학습 상황 제외에 E3도 포함한다.
