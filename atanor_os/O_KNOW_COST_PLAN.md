# O단계: 미리 아는 것이 실험을 아끼는가 (2026-11-10, 개발 실행과 새 시드 전에 고정)

## 왜

N단계에서 남이 쓴 세계로 배운 읽기 모형(`reader-all5`)이 실제 몸의 모름을 줄였다(.550 → .669, 추가 틀림 0). 새로 맞힌 것은 거의 모두 "이 호출은 거절된다"였다. I단계에서는 읽기 모형이 실험 **순서**만 정했고 학습 비용이 줄지 않았다(0/6). 이번에는 아는 것을 **쓴다**: 읽기 모형이 확신하는 호출은 해 보지 않고, 예측은 혼성이 한다. 삶의 지표는 같은 정답률에 닿는 데 드는 스스로의 실험 수다.

## 설계

- 과정 뒤 연습 세계에서 행동당 k ∈ {0, 1, 2, 3, 5, 10}번까지 실험한다(`rebuild/explore.py`, 개발과 같은 연습 세계 규칙).
- **NONE:** 오늘의 CHOOSE(기호 마음이 모르는 호출, 새 값이 많은 것 먼저), 예측은 기호 마음.
- **all5:** 같은 순서이되 읽기 모형이 τ0.95 이상으로 확신하는 호출은 시험하지 않는다. 예측은 혼성(기호 마음 + 기호 마음의 모름에만 읽기 모형, τ0.95, 표결 1, k=10). 예시는 그 몸의 과정과 그때까지의 실험뿐이다.
- **k1:** 같은 규칙, 내 문법만으로 배운 `meta-k1`(대조).
- 몸마다 목표 = NONE의 k=10 정답률 × 0.95. 조건마다 목표에 처음 닿는 k에서의 총 실험 수 T(k=0이면 0).
- 러너: `memory/know_cost.py`.

## 기준

| 기준 | 내용 |
|---|---|
| O1 비용 | 여섯 몸 중 넷 이상에서 T(all5) ≤ 0.7 × T(NONE) |
| O2 안전 | 각 몸의 모든 k에서 all5 틀림률 ≤ NONE 틀림률 + 0.5%p |
| O3 출처 | O1을 통과한 몸의 절반 이상에서 T(all5) < T(k1) |

- **통과:** O1·O2·O3. 개발 시드(1–3)에서 먼저 재고, 설정을 바꾸면 그 사실을 적는다. 최종은 **새 시드: 과정 2401–2403, 평가 세계 2501–2503**(어디에도 쓰지 않음)에서 한 번.

## 한계

- 개발에 쓴 몸이다. 프로그램 교사 결과다. 연습 세계가 무해한 곳에서만 성립한다.
- 예측 벤치 위의 학습 비용이다. 일하기 GOOD이 아니다.
- 읽기 모형의 학습 자료는 ATANOR의 삶이 아니다.
- 기호 마음이 행동당 몇 번이면 끝나는 몸(fs)은 줄일 여지가 없다.
