## SLM 비교 (E3)

정답률 / 틀림률이다. SLM은 과정 경험과 ATANOR의 X10 실험을 함께 받았다. 받은 것은 ATANOR와 똑같다.

| 몸 | ATANOR | qwen2.5 7B | llama3.1 8B | exaone3.5 7.8B | gpt-oss 20B |
|---|---|---|---|---|---|
| board | 1.000 / 0 | 0.765 / 0.235 | 0.696 / 0.304 | 0.614 / 0.386 | 0.919 / 0.081 |
| clime | 0.988 / 0 | 0.539 / 0.456 | 0.768 / 0.232 | 0.822 / 0.178 | 0.935 / 0.064 |
| desk | 0.999 / 0.001 | 0.797 / 0.193 | 0.843 / 0.157 | 0.822 / 0.178 | 0.995 / 0.005 |
| fs | 1.000 / 0 | 0.973 / 0.027 | 0.676 / 0.324 | 0.667 / 0.333 | 0.996 / 0.004 |
| view | 0.962 / 0 | 0.652 / 0.348 | 0.265 / 0.735 | 0.523 / 0.477 | 0.917 / 0.083 |

- **판정:** 20칸 모두 ATANOR 우위다. 정답률이 더 높고, 동시에 틀림률이 더 낮다. 미리 고정한 규칙에 따라 **이 과제에서 "능가"**다.
- **잘못된 답:** qwen의 clime에서 1개뿐이었다.
- **경험 잘림:** fs 질의 340개가 30,000자 예산을 넘었다. 그래서 오래된 과정 경험부터 잘렸다.
- **격차:** 가장 가까운 상대는 gpt-oss다. desk에서는 0.999 대 0.995, fs에서는 1.000 대 0.996으로 차이가 작다.
- **실험 경험의 효과:** 실험 경험은 SLM에도 크게 도움이 되었다. 지난 비교에서 desk의 gpt-oss는 0.512였고, 이번에는 0.995다. 이번 우위의 대부분은 **ATANOR가 스스로 고른 실험**에서 나왔다. 경험을 해석하는 능력의 차이는 그보다 작다.

## 틀림 4건 (모두 desk 시드 962)

- 지난 비교와 같은 종류다. `shelve('f.archive')`를 `locked`인 메시지에 쓰면 실제로는 `failed`인데, ATANOR는 `ok`를 예측했다.
- 실험이 이것을 고치지 못한 이유가 있다. 실험 후보는 BAYES 0.99가 **모르겠다고 하는** 호출뿐이다. 그런데 이 호출은 과정 경험만으로 이미 확신하는(그러나 틀린) 호출이다. 그래서 시도 대상이 되지 않았다.
- 고르는 규칙이 처음 보는 시작 값을 세는 데에 그치고, 확신하는 예측을 다시 시험하지 않는다는 한계가 드러났다.
- 개발 시드에서는 X10의 틀림이 0이었다.

## 한계

- 실험할 수 있는 몸에서만 성립한다. 실험실 복사본이 있고, 시도해도 해가 없는 몸이다.
- 연습 세계는 평가 세계와 같은 생성기에서 나온다. 다른 분포에서의 결과는 주장하지 않는다.
- 이것은 예측 과제의 능가다. 언어, 일반 지식, 열린 과제에서 SLM을 능가한다는 뜻이 아니다.
- 실험을 학습기(`next_noask`)의 실제 행동에 붙이는 일은 아직 하지 않았다.
- 경험이 있는 질의만 쓰도록 걸러 냈다. 이번 실행에서는 걸러 낸 질의 수를 세지 않았다.
