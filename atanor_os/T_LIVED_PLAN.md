# T단계: 한 삶에서, 남의 세계로 배운 앎이 에너지를 남기는가 (2026-11-10, 새 시드 전에 고정)

## 왜

창립자 지침은 호출별 점수가 아니라 **삶**을 평가하라는 것이다. 에너지와 한 번의 죽음이 있는 삶(G단계의 `life/host.py`, `metabolism.py`)에서, R단계의 읽기 모형(자기 점검 문 0.8, τ0.9)이 연습 중 확신하는 호출을 해 보지 않게 한다. 일하는 중 판단은 바꾸지 않는다(P에서 일하는 중 대신하기는 clime에서 일을 잘못해 닫았다).

## 설계 (`life/lived_know.py`)

- Self 하나 = 기본 유전자(`DEFAULT_GENOME`), 빈 마음, 프로그램 교사. board·clime을 4회씩 산 뒤 dye를 4회 산다. 각 몸의 과정 뒤 연습(에너지 0.3/시도, 유전자의 예산·G(a) 규칙 그대로).
- **NONE:** 오늘의 연습. **KNOW:** 같은 연습에서 읽기 모형이 확신하는 호출은 시도하지 않는다(비용 없음).
- 잰 것: 새 몸 dye의 평가자 GOOD(`measure`), 교사 명령 GOOD, 끝의 에너지 E, 스스로의 시도 수, 죽음.

## 개발 (시드 1–3)

| 시드 | GOOD NONE / KNOW | 끝 에너지 NONE / KNOW | 스스로의 시도 NONE / KNOW |
|---|---|---|---|
| 1 | 1.000 / 1.000 | 49.6 / 54.1 | 123 / 108 |
| 2 | .842 / .842 | 58.7 / 62.3 | 85 / 73 |
| 3 | .594 / .594 | 50.7 / 54.3 | 87 / 75 |

## 시험 (한 번): 새 시드 3101–3105 (P에서 예약했으나 열지 않음)

| 기준 | 내용 |
|---|---|
| T1 일 | 다섯 시드 합 dye GOOD(평가자)이 KNOW에서 NONE보다 1%p 넘게 낮지 않고, 교사 명령의 wrong이 늘지 않는다 |
| T2 에너지 | 다섯 중 넷 이상에서 끝 에너지 KNOW > NONE |
| T3 삶 | KNOW Self가 하나도 죽지 않는다 |

- **통과:** T1·T2·T3.

## 한계

- 효과는 작다(개발에서 끝 에너지 +7%). 연습 비용만 줄인다. 몸 셋, 프로그램 교사, dye는 개발에 쓴 몸. 읽기 모형의 학습 자료는 ATANOR의 삶이 아니다.
