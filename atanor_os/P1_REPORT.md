# ATANOR OS P1 — 첫 보고 (헌장 v0.1 §10 형식)

2026-10-24. 브랜치 `atanor-os/p1-vertical`(커밋 없음, 소스 sha256 `83947f41b9fc6dce` 기준 v2). 상태 표기: **구현됨 / 시험됨 / 가설 / 막힘**.
이 문서의 어떤 수치도 AGI·의식·일반 지능·자기개선의 증거가 아니다.

## 1. 선택한 최소 구현과 이유

**선택:** 생성된 소형 파일 작업 공간(실제 디스크) 위에서 `관측 → 계획 → 의도 기록 → 권한 검사 → 실제 실행 → 재관측 → 검증` 루프를 돌리고, 도구의 **전제조건·효과를 성공/실패 대조로 유도하는 관계 규칙 학습 + 예산 제한 최선우선 탐색**을 첫 가설로 두었다 (`atanor_os/`, 표준 라이브러리만, 약 1,300줄).

**이유:** CPU에서 돌고, 실패를 표현/학습/검색/계획/관측/평가로 분리해 진단할 수 있으며, 기존 Whole Mind의 교훈(관측과 믿음의 분리, 행동 후 재관측, 평가기 분리)을 가져오되 영구 INTERRUPTED·평생 예산·임시 폴더 강제·정확한 타입 제한은 계승하지 않는다(헌장 §1). 이것이 정답이라는 믿음은 없다 — §6의 결과가 그 범위를 보여준다.

사용자 제안 "마기형 세 자아 의결"은 아키텍처가 아니라 **비교군 D**로 사전등록해 같은 예산에서 시험했다(§5). 의식·창발은 조작적 시험이 없으므로 목표에서 제외했다.

## 2. 사람이 제공한 지식 vs 실제 학습한 것

| 제공(BOOTSTRAP_MANIFEST) | 학습 대상 |
|---|---|
| 객체 ID(경로), 관측 속성 `kind/ext/hash/parent_kind`, `same_content` 관계, 역할 변수로 들어올리는 서명(해시 값 제외) | — |
| 도구 5개의 서명과 **효과 설명**(참이지만 불완전: 전제조건·실패 조건 없음) | 각 도구의 전제조건(예: copy는 원본 file·대상 absent·부모 dir), 설명서에 없는 효과·제약(move는 파일만, convert는 txt→md) |
| 목표 구조(must/keep/capability/예산/우주), 예산 제한 planner, 같은 상태에서 실패한 행동 회피 | 새 객체·확장자·깊이·조합에 규칙을 적용하는 것 |
| 고정 탐색 정책(도구 균등 + 미경험 서명 2회까지 우선, 300행동, 조건 무관 동일 로그) | — |

**실제로 학습된 것(v2, seed 5개의 C 모델, `results/p1-test-02/eval_s*/model_C.json`):** mkdir·copy·delete의 전제조건이 **5/5 seed에서 진실 모델과 정확히 일치**, move는 4/5(seed 2는 `parent_kind(?a1)=dir` 누락 — 대조 사례 부재), convert는 seed 1만 지지 2회·과잉 일반화, seed 4·5는 가설(1회), seed 2·3은 성공 0회로 **학습 없음**(설명서 폴백). 효과 `hash(?a1)←hash(?a0)`(copy/move)는 전부 정확. "설명서에 있던 것을 읽은 것"과 "경험으로 발견한 것"은 보고서의 `설명서의존`(실행 행동 중 설명서만으로 예측한 비율: C 0.18, A 1.00) 열로 분리된다.

## 3. 첫 과제, 비교군, 예산, 누출 방지

- **과제(test 분할):** backup(복사·원본 보존) / sort(확장자별 이동·원본 제거, 디렉터리 체인 필요) / convert(txt→md, 출력이 관측 가능한 모든 파일과 내용이 달라야 함 — v2) × 20과제(템플릿 균등), 새 이름·새 디렉터리·파일 3–4개·확장자 log/json·깊이 2 목표 체인. 평가기가 ORACLE(진실 모델)로 20/20 도달 가능을 확인.
- **비교군:** A 고정 지식(설명서) · B 경험 검색(정확 서명 일치) · C 규칙 학습(B 포함) · D 의결(경험 3등분 C 3개, 근거 있는 구성원만 투표) · ORACLE(진단). 차이점 표는 `EXPERIMENT_PROTOCOL.md`.
- **예산(동일):** 행동 ≤ 20, 예측 호출 ≤ 400,000/계획 호출(구속, 결정적), 확장 ≤ 600, 깊이 ≤ 12, 시간 180 s(안전장치). 탐색 300행동/seed. 표본 20과제 × 5 seed × 4조건 = 400 + ORACLE 20.
- **누출 방지:** `agent/·core/·world/`는 `eval/`를 import하지 않음(AST 기반 테스트 + 동적 import 금지), 학습기는 Goal과 작업 공간만 받음, 평가 seed·템플릿·진실 모델은 `eval/`에만, 최종 test는 `protocol.json` 동결 후 1회(v1), 결함 수정 후 새 버전으로 다시 1회(v2). 판정 규칙: C−B ≥ 10 pp ∧ seed ≥ 4/5 ∧ 비용비 ≤ 3 → `VALID_BOUNDED_GAIN`.

## 4. 구현한 수직 경로와 재현 명령 (구현됨·시험됨)

```
python -m pytest atanor_os/tests -q                                   # 15 passed (명세·누출·평가기 타당성; 학습 증거 아님)
python -m atanor_os semantics --k 20 --seed 7                          # 진실 모델 vs 실제 파일시스템, 도구×결과 셀당 20회
python -m atanor_os pilot --split test --seeds 1,2,3,4,5 --tasks 20 --steps 300 --conditions A,B,C,D --out atanor_os/results/<name>
```
`pilot`은 seed마다 탐색 → A/B/C/D 평가 → ORACLE(seed 1) → `records.jsonl`(에피소드별 원본), `metrics.json`, `REPORT.md`, 조건별 `journal_*.sqlite`(의도→실행→검증 기록), `model_*.json`(학습된 규칙), 탐색 로그를 남긴다. 실제 결과 디렉터리: `results/p1-test-01`(v1), `results/p1-test-02`(v2), `results/p1-test-hp-v1`(HP 복제), `results/magi-review-01.json`(독립 검토).

**v1→v2 차이의 의미:** 독립 검토가 찾은 평가기 결함(convert 과제가 copy로 만족됨, wall-clock 상한이 D에만 작동, test에 json 미생성 등 19건)을 고친 뒤에도 C−B 이득은 유지됐고, D는 투표 규칙 수정으로 0.37→0.61로 올랐으나 여전히 C보다 낮다. v1은 보존되며 convert 수치는 "지정 경로에 파일 만들기"로 읽어야 한다.

**추가 적응 허용(헌장 §8 "학습 상태 고정 vs 추가 적응"):** 평가 중 각 행동의 결과로 모델을 갱신하게 하면 B가 0.21→**0.59**(backup 0.89, convert 0.93, sort 0.00), C는 0.84→0.81(convert 1.00→0.87), C−B는 +22 pp로 줄고 B−A는 +39 pp가 된다. 해석: frozen 조건에서 C가 B를 크게 앞선 것의 상당 부분은 **탐색 로그에 없는 상황으로의 일반화**(B는 정확 일치라 불가)이며, 과제 안에서 경험을 쌓게 하면 검색만으로도 1–2단계 과제는 회복된다. 반면 디렉터리 체인이 필요한 sort는 적응을 허용해도 B가 0.00 — 유도된 규칙의 고유 이득은 **다단계 계획**에 있다. C의 convert 하락(−0.13)은 원인을 분리하지 못했다(후보: 에피소드 안의 1표본 규칙이 효과를 잘못 고정). 이 실행은 판정에 쓰지 않는다.

### 5.2 HP 노트북 복제 (i7-6700HQ, Windows 10, Python 3.13.17 사용자 설치) — `results/p1-test-hp-v1`

v2 코드 복제(`p1-test-hp-v2`, A/B/C × seed 1–3, D는 비용 때문에 제외): A 0.20 · B 0.20 · **C 0.733** · ORACLE 1.00. 이 PC의 같은 seed 부분집합과 **180/180 에피소드에서 완수 여부와 행동 순서가 완전히 일치**(소스 sha256 동일 `83947f41b9fc6dce`). 즉 v2의 예측 횟수 예산은 결과를 **기계 독립적**으로 만들었다. 비용: HP wall A 9.1 s · B 8.6 s · C 16.3 s · ORACLE 3.2 s(이 PC 대비 2.2–2.4배), 최대 메모리 C 77 MB(동일), 학습 비용 ≤ 0.03 s. ### 5.3 실패 원인 좁히기 (헌장 §6)
C의 v2 실패 16건(seed 2: 10, seed 3: 6)은 모두 sort/backup이며 원인은 두 가지로 분리된다.
1. **획득 데이터 부족 → 과잉 일반화(seed 2):** move 규칙에 `parent_kind(?a1)=dir`가 빠졌다. 탐색 57회 중 "부모 없는 경로로 이동" 실패가 한 번도 없어서 그 리터럴을 떨어뜨리는 것이 데이터와 모순되지 않았다. 평가에서는 디렉터리를 만들기 전에 move를 시도 → 실패 → 회피 → 다른 move → … 19회 no-op. 규칙 유도 로직은 설계대로("가장 일반적인 일관 가설") 작동했고, 틀린 것은 **데이터**다.
2. **미학습 도구의 설명서 폴백 → 탐색 오도(seed 3):** convert 성공 0/66으로 규칙이 없고, 설명서는 "항상 성공"이라 planner가 h를 줄이는 듯 보이는 convert 가지(파일 kind만 바꿈)를 대량 전개하다 첫 계획 호출에서 600노드 상한 → 6개 sort 과제에서 행동 0. 표현도 규칙도 아니라 **낙관적 폴백 + 탐색 예산**의 상호작용이다.
v1의 C 실패 16건(sort 전부·행동 0)도 같은 탐색 실패였고, seed 4·5는 검토 에이전트 49개가 CPU를 쓰던 시간에 돌아 wall-clock 상한이 더 일찍 걸렸다(v2에서 예측 횟수 상한으로 제거).

### 5.4 독립 검토 (MAGI형, `results/magi-review-01.json`)
검토자 3명(누출·공정성·평가)이 제 결론 없이 코드만 보고 23건을 제시, 각 건을 2명이 반박 시도 → **19건 확정, 4건 반박**. 확정 건은 전부 v2에 반영하거나(17건) 구조적 한계로 문서화(2건: 차단 제안 0, B 커버리지 한계). 처리 내역은 `DECISIONS.md`.

### 5.6 아직 주장할 수 없는 것
- 생성된 파일 퍼즐 밖의 일반화, 자유 언어, UI, 실제 사용자 자료, 자기 코드 수정, AGI·의식.
- D의 결론은 "경험을 3등분한 의결"에 한정된다. 같은 데이터를 보는 다양한 학습기의 의결은 시험하지 않았다.
- 20과제 × 5 seed는 같은 학습 상태에서 나온 비독립 표본이며 신뢰구간을 제시하지 않았다. `VALID_BOUNDED_GAIN`은 사전 기준 충족을 뜻할 뿐이다.
- 탐색 정책은 학습기의 서명 표현을 쓴다(정답 경로는 없지만 표현 의존). B는 정확 일치라 C−B에는 "커버리지 밖 일반화"가 섞여 있다 — 적응 허용 실행이 그 크기를 보여준다(+63 → +22 pp). 규칙 학습의 고유 이득은 다단계 과제(sort)에서만 확실하다.
- 결과는 커밋되지 않았다(사용자 요청 시 커밋). 소스 해시는 `metrics.json → env`에 있다.

## 6. 다음 한 가지 변경 가설

**가설 H1(획득 정책):** 고정 탐색 정책을 "성공이 가장 적은 도구를 우선 시도하고, 학습된 규칙이 리터럴을 떨어뜨릴 때 그 리터럴을 직접 시험하는 행동(대조 탐색)을 섞는" 정책으로 바꾸면, 같은 300행동에서 move·convert 규칙이 5/5 seed에서 `supported`가 되고 C의 sort 실패(§5.3-1·2)가 사라진다.
- 측정: 현재 고정 정책(v2) 대비, 같은 예산·같은 test 분할, 새 실험 이름으로 동결 후 1회. 성공 기준: C−B 유지 + C sort 완수율 ≥ 0.9, 과잉 일반화 규칙 수 0.
- 기각 시: 원인이 획득이 아니라 탐색(§5.3-2)이므로 대안 H3 "설명서 폴백 단계의 비용 상향/근거 없는 행동 보류"를 다음 단일 가설로 둔다.
- 중단 조건: H1·H3 모두 이득 없음이면 "관계 규칙 + 탐색" 가설의 확장을 멈추고 표현(예: 부재 객체의 부모 관계 명시) 쪽으로 돌아간다.

이 보고의 상한 횟수(가설 변경 3회)는 `RESEARCH_CONTRACT.md` 미결 항목이다.
