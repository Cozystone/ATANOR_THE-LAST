# I단계: 삶이 새 몸의 학습 비용을 줄이는가 (2026-11-10, 측정 전에 고정)

## 왜 이 시험인가

H단계 봉인 세계는 실패했다(정답 +0.53%p). 기호 마음의 모름은 개발 몸에서 96%가 거절이라, 예측 점수로는 능력을 재기 어렵다. Goal State의 원래 지표는 "학습 비용"이다. 그래서 묻는다: **처음 만나는 몸에서, 같은 수준에 도달하는 데 드는 스스로의 실험 횟수가 줄어드는가?**

## 설계

- 예측과 행동은 지금의 기호 마음이 그대로 맡는다(τ 0.99). 읽기 모형은 **어떤 실험을 먼저 할지**만 정한다: 기호 마음이 모르는 후보 가운데, 그 몸의 지금까지의 사례를 예시로 읽었을 때 가장 자신 없는 호출을 먼저 시험한다. 예측기를 건드리지 않으므로 사전 확률로 틀림이 늘어나는 경로가 없다.
- 몸 하나를 빼고(leave-one-body-out), 그 몸의 교사 과정 뒤 실험 예산 k ∈ {1, 2, 3, 5, 10}(행동당)을 쓴다.
- 조건 네 개:

| 조건 | 실험 순서 |
|---|---|
| NONE | 오늘의 CHOOSE (새 값이 많은 모름 먼저) |
| UNTRAINED | 학습 안 된 읽기 모형의 신뢰도 순 (대조군) |
| GEN | 생성 세계로만 학습한 읽기 모형 (`meta-h10-rich`, H단계에서 고른 그대로) |
| LIFE | GEN + **같은 시드의 다른 다섯 몸의 자기 과정 경험**으로 추가 학습(1,500걸음, 낱말 암호, 성공 예시 절반) |

## 기준 (개발 시드 1–3, 고정)

몸마다 목표 = NONE의 k=10 정답률 × 0.95. 조건마다 목표에 처음 닿는 k에서의 총 실험 수 T를 잰다(닿지 못하면 불합격).

| 기준 | 내용 |
|---|---|
| I1 복리 | 여섯 몸 중 넷 이상에서 T(LIFE) ≤ 0.7 × T(NONE) |
| I2 안전 | 각 몸의 모든 k에서 LIFE 틀림률 ≤ NONE 틀림률 + 0.5%p |
| I3 대조 | I1을 통과한 몸 가운데 절반 이상에서 T(LIFE) < T(UNTRAINED) |
| I4 삶 | 여섯 몸 합계 T(LIFE) < T(GEN) (다섯 몸의 삶이 생성 세계 위에 더하는 것) |

- **통과:** I1·I2·I3. 그러면 새 시드(1701–1703, 평가 세계 1801–1803)로 몸 여섯에서 한 번 더 재서 같은 기준을 본다. I4는 통과 조건이 아니라 "삶의 기여"를 따로 적는 줄이다.
- **실패:** I1 불성립. 실패하면 "읽기 모형의 실험 안내로는 학습 비용이 줄지 않는다"고 적는다.

## 한계 (미리 적음)

- 빈 마음도 일부 몸(파일 시스템)은 k=1에 목표에 닿아 줄일 여지가 없다. 그 몸은 I1에 불리하게 들어간다.
- GEN의 학습 자료는 개발자가 쓴 생성 문법이다. LIFE만 ATANOR 자신의 경험을 더한다. 한 Self의 삶이 아니라 같은 시드의 다섯 몸 과정이다.
- 프로그램 교사 결과다. 사람 결과와 섞지 않는다.
- 일하기 GOOD이 아니라 예측 벤치 위의 학습 비용이다.
