F(`GEN3_F_RESULTS.md`)는 어느 몸에서도 틀림을 늘리지 않았다. 기후실 틀림은 3 → 0, 데스크의 다시 보내기·실패 재시도는 0이 됐다. 그러나 사례가 없는 칸을 두어 성공 비율이 기준보다 크게 떨어졌다. 연결 층의 두 번째이자 마지막 가설이다.

## 바꾸는 것 (F와 한 곳만 다름)
사례를 남기는 방법은 F와 같다. 시범과 자기 행동마다 대상의 직전·직후 관측 원자를 남기고, 막힌 행동은 남기지 않는다.

혼자 있을 때, 개념이 고른 대상마다 같은 행동의 사례로 다음과 같이 정한다.

| 사례들의 뜻 | 학습기가 하는 일 |
|---|---|
| 바뀜에 동의하고, 이 대상이 결과 값을 아직 다 갖지 않음 | 한다 |
| 바뀌지 않음에 동의, 또는 결과 값을 이미 다 가짐 | 둔다(반례 아님) |
| **사례가 없거나 엇갈림** | **지금 코어처럼 한다**(행동 주장의 결과 값으로 '이미 됐는가'를 본다). 그 대상의 필요한 근거는 주장으로 남긴다. |

- D와 다르다. 명령 전체를 보류하지 않는다.
- F와 다르다. 사례가 없는 대상을 두지 않는다.
- 사람이 있을 때, 그리고 다른 대상을 만드는 행동은 지금과 같다.
- 몸·낱말 지식을 넣지 않는다.
