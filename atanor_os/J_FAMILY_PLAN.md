# J단계: 한 세계 가족 안에서, 여러 세계를 산 것이 새 세계를 싸게 하는가 (2026-11-10, 최종 실행 전에 고정)

## 질문

H(다른 가족의 봉인 세계)와 I(실제 여섯 몸의 학습 비용)는 실패했다. 문헌은 전이가 **공유된 구조만큼** 일어난다고 말한다(`reports/전이 복리 최신 연구 조사.md`). 그러면 구조를 공유하는 세계들 사이에서는 일어나는가? 이것이 일어나지 않으면 이 길 전체가 근거를 잃는다. 일어나도 "먼 전이"는 아니다.

## 설계

- 가족: `memory/worlds.py`(풍부한 문법). 읽기 모형 `meta-h10-rich`는 가족 시드 1의 세계 4,000개로 학습됐다. 평가 세계는 그 학습에 없던 세계다.
- 각 평가 세계: 도구마다 과정 n개(생성기가 뽑는 그대로, 6 / 12 / 24), 질의 12개. 기호 마음은 과정만 배운다. 혼성은 기호 마음의 모름에만 읽기 모형을 쓴다(τ0.9, 표결 3, k=10 — H에서 고정한 그대로).
- **개발 (이미 봄):** 가족 시드 2, 세계 60개. 과정 6: 기호 R .129 / W .0033 → 혼성 .241 / .0116. 과정 12: .519 / .0037 → .587 / .0054. 과정 24: .797 / .0029 → .816 / .0037.
- **최종 (한 번):** 가족 시드 977, 세계 200개, 같은 설정.

## 기준

| 기준 | 내용 |
|---|---|
| J1 | 과정 6에서 혼성 정답률 ≥ 기호 + 5%p, 틀림 증가 ≤ 1%p |
| J2 | 과정 12에서 혼성 정답률 ≥ 기호 + 3%p, 틀림 증가 ≤ 1%p |

- 둘 다면 **통과**, 하나면 **부분**, 없으면 **실패**.

## 뜻과 한계 (미리 적음)

- 통과해도 "같은 생성 문법을 공유하는 세계들 사이의 전이"다. 다른 가족(H 봉인 세계)에서는 +0.53%p였다.
- 가족의 문법은 개발자가 썼다. 학습 자료는 ATANOR의 삶이 아니다.
- 과정은 무작위 시도라 교사 과정(성공 위주)과 분포가 다르다.
- 이것은 돌파가 아니다. 문헌이 이미 보인 범위의 전이를 우리 판정법으로 확인하는 일이다.
