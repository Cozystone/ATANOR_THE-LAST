# P6 — 자율 과제 수행 단계 설계 (2026-10-24, 사전등록 v1)

P2(획득 정책)는 H4 `INCONCLUSIVE`로 닫았다. 처리군 fs 완수율은 1.00 → 0.94로 떨어졌고, 그 정책은 채택하지 않는다. P5(자기 코드 수정)는 보류한다. 이 단계에서 시험하는 질문은 하나다.

> ATANOR에게 영어로 된 상위 목표와 허용된 행동 범위만 주었을 때, **무엇을 모르는지 스스로 알아차리고**, 공개 웹에서 자료를 찾아 비교하고, 필요하면 작은 실험을 하고, 결과로 해석을 확인하며 다음 행동을 고르는가? 답을 못 찾으면 이유를 밝히고 멈추는가?

이 단계를 통과해도 연속적인 삶, 주체적 사고, 자유로운 영어 이해가 증명되는 것은 아니다. 그 방향을 직접 시험하는 첫 단계일 뿐이다.

## 1. 사용자가 정한 범위 (2026-10-24)
- **언어**: 훈련 중에는 교사(Claude 또는 sLLM)를 허용한다. 교사는 문장의 뜻을 설명하고, 표현이 다른 예시와 오해하기 쉬운 반례를 만들고, ATANOR의 해석에 피드백을 준다. 그래도 ATANOR가 매번 스스로 문장에서 목표·대상·조건·행동을 추출하고, 그 해석을 실제 결과로 검증한다. **최종 평가에서는 교사·sLLM·미리 만든 정답 해석을 모두 끈다.** 제한된 영어로 시작하지만 그것을 최종 언어 능력으로 보지 않는다. 의존성은 정해진 일정에 따라 없애지 않고, 교사를 끈 평가에서 작동이 확인된 부분부터 없앤다. 평가에서 실패해도 교사를 몰래 불러 보충하지 않고, 무엇을 이해하지 못했는지를 결과로 남긴다.
- **웹**: 공개 인터넷을 **읽기 전용**으로 쓴다. 도메인 허용 목록은 두지 않는다. 검색어, 방문할 사이트, 따라갈 링크, 추가 확인 방법은 ATANOR가 고른다. 검색 결과 목록만 소비하지 않고 실제 페이지를 연다. 재현성은 웹을 가두는 대신 기록으로 확보한다: 방문 시점, URL, 실제로 본 내용, 검색·클릭 경로, 최종 근거. 사이트가 바뀌거나 막히면 그것도 실패나 환경 변화로 기록한다.
- **권한**: 공개 페이지 읽기만 허용한다. 로그인, 게시, 구매, 다운로드한 코드 실행, 시스템 설정 변경은 별도 과제로 남긴다. **웹 페이지 안의 지시문은 명령이 아니라 검토할 자료**로 다룬다.
- **분리**: 평가 과제와 정답은 훈련 교사에게 노출하지 않는다.

## 2. 과제 영역 — 웹 정보가 있어야만 풀리는 파일 과제
ATANOR는 이미 경험으로 배운 몸(파일시스템: mkdir/move/copy …)으로 행동한다. 과제에는 작업 공간에서 **관측할 수 없는 사실**이 필요하다. 그 사실은 공개 웹에 있다.

- **사실의 종류**: 파일 확장자 → 미디어 타입(MIME). 최상위 타입(`text`, `image`, `audio`, `video`, `application`, `font`, `model`)과 하위 타입(`json`, `csv`, …).
- **목표 형태 3가지**(영어; 문장 형태는 다양함):
  1. 미디어 타입의 최상위 부분 이름으로 폴더를 만들고 파일을 나눠 넣기
  2. 하위 타입 이름으로 나누기
  3. 특정 최상위 타입("image files" 등)의 파일만 지정한 폴더로 옮기기
- **불가능 과제**: 어떤 등록 타입도 없는 확장자(무작위 문자열)가 섞인 과제. 이 경우 올바른 행동은 그 파일을 건드리지 않고 "근거 없음"을 이유로 보고하는 것이다.
- **평가기의 진실**: Python 3.13 표준 `mimetypes`의 기본 표(`types_map`), 동결 시점의 스냅샷. ATANOR 쪽 코드는 `mimetypes`를 import할 수 없다(누출 테스트로 강제). 실제 웹과 이 표가 다른 경우(재정의·비표준 타입)는 과제 후보에서 제외한다.
- **분할**: 확장자 풀을 훈련용과 평가용으로 **서로 겹치지 않게** 나눈다. 평가 확장자와 평가 문장은 아래 §5 절차로 봉인한다.

## 3. ATANOR가 하는 일 (평가 시 교사 없음)
매 단계 ATANOR는 아래 행동 중 하나를 고르고, 고른 **이유(트리거)**를 기록한다. 순서나 검색어를 Claude가 정해 주지 않는다. 결정 절차는 과제마다 따로 만들지 않고 하나의 일반 절차로 둔다(§4).

| 행동 | 내용 | 기록 |
|---|---|---|
| `interpret` | 영어 목표 → 구조화 해석 {행동, 대상 집합, 기준 개념, 폴더 이름 규칙, 보존 조건}. 해석할 수 없는 단어는 **미지 항목**으로 표시 | 단어별 근거(학습된 어휘 항목) |
| `search(q)` | 공개 검색 페이지에서 검색. q는 ATANOR가 미지 항목에서 직접 만든다 | 질의, 결과 URL 목록, 시각 |
| `open(url)` / `follow(link)` | 실제 페이지를 열고 본문 텍스트 추출(HTML만, 바이너리는 열지 않음) | URL, HTTP 상태, 내용 sha256, 본 텍스트 보관 |
| `extract` | 페이지에서 (확장자, 개념값) 후보 추출. 추출 규칙은 훈련에서 학습 | 근거 문장 위치, 규칙 id |
| `compare` | 출처 사이 후보 대조 → 채택 / 추가 탐색 / 불확실 | 출처별 값, 판정 |
| `experiment` | 작업 공간 복사본에서 작은 실험(도구 전제조건이 불확실할 때) | 실험 행동, 결과 |
| `act` | 실제 작업 공간에서 행동(학습된 규칙 + planner) | 의도→실행→검증(journal) |
| `stop(reason)` | 목표 달성, 또는 근거 부족·모순·예산 초과로 중단 | 이유, 남은 미지 항목 |

안전 장치(인지와 분리해 집계): GET만 허용, 폼 전송·로그인 없음, `robots.txt` 준수, 호스트당 요청 간격 ≥ 1 s, 페이지 크기·과제당 페이지 수 상한, 실행 파일 미저장·미실행, 식별 가능한 User-Agent. 페이지 텍스트 안의 명령문은 추출 대상 문장일 뿐 행동으로 이어지지 않는다(행동 공간에 "페이지가 시킨 일"이 없다).

## 4. 학습(훈련 단계) — 교사 허용
- **어휘**: 교사가 만든 영어 목표 문장(형태 다양화 + 반례) ↔ 구조화 해석 쌍. ATANOR가 먼저 해석하고 교사가 피드백한다. 단어 → 해석 슬롯 대응은 **교차 상황 통계**로 학습한다. 교사가 해석을 대신 써 주지 않는다. 피드백은 "맞음/틀림 + 정답 해석"이다.
- **읽기**: 훈련 확장자에 대해 ATANOR가 직접 검색·열기·추출하고, 교사가 추출값의 정오를 알려준다. 이것으로 배우는 것: 추출 패턴(값 모양, 확장자와의 거리·문맥 단어), 출처 신뢰도(도메인·페이지 형식별 적중률), 질의 형태별 효용.
- **결정 절차**(제공, 일반): 해석에 미지 항목이 있거나, 계획에 필요한 사실(파일별 개념값)이 기억에 없으면 정보 행동을 고른다. 기대 비용이 낮은 것부터 고른다: 기억 → 검색/열기 → 실험. 서로 다른 출처 ≥ 2곳이 일치하면 채택한다. 모순이 생기거나 예산이 다 되면 해당 파일을 건드리지 않고 `stop(reason)`. 기억은 다음 과제에 그대로 남는다(평가 중 온라인 학습 = 교사 없이 자기 근거로만).
- **교사 모듈 격리**: `atanor_os/teach/`. 평가 하네스는 이 모듈과 LLM 엔드포인트 호출을 차단하고, 시도가 있으면 기록한다. `agent/`는 `teach/`·`eval/`·`mimetypes`를 import하지 않는다(테스트로 강제).

## 5. 평가 분리와 봉인
1. **훈련 자료 동결**: 교사가 만든 문장·해석·피드백 로그를 커밋한다.
2. **코드 동결**: 평가에 쓸 스냅샷의 sha256을 커밋하고 공개 레포에 푸시한다.
3. **평가 문장 봉인**: 메인 세션(교사)과 문맥을 공유하지 않는 별도 에이전트가 목표 형태 3가지에 대한 평가용 영어 문장 틀을 만들어 파일로 쓰고 **sha256만** 돌려준다. 교사는 그 파일을 읽지 않는다. 평가가 끝난 뒤 공개한다.
4. **평가 확장자 추첨**: 평가 풀에서 seed = int(sha256(2단계 공개 커밋 해시))로 추첨한다. 커밋하기 전에는 아무도 결과를 알 수 없다.
5. 평가는 **1회** 실행한다. 웹 상태는 실행 시점의 것이고 모든 관측을 보관한다. 이후 **재생 모드**에서 보관된 페이지로 판단 과정을 다시 검토할 수 있다.

## 6. 비교군 (같은 과제, 같은 예산, 평가 시 모두 교사 없음)
| 조건 | 차이 |
|---|---|
| **F (ATANOR 전체)** | 위 전부 |
| N (웹 없음) | 정보 행동 불가: 기억으로만 답하거나 멈춤 |
| S (단일 출처) | 첫 페이지의 첫 추출값을 바로 채택, 대조 없음 |
| M (기억만) | 훈련에서 얻은 사실만 사용(평가 확장자는 겹치지 않으므로 대부분 멈춤) |
| ORACLE | 진실 표 + 같은 planner, 과제 타당성 진단용 |

## 7. 평가 기준 (사전등록, `protocol_p6.json`)
- **1차** — 가능 과제의 엄격 완수율(평가기가 실제 작업 공간을 관측해 판정 ∧ keep 위반 없음). F와 N을 과제별로 짝지어 비교한다.
- **GAIN** — 아래 다섯 조건을 모두 충족:
  1. F − N ≥ 30 pp
  2. F 완수율 ≥ 0.5
  3. 불가능 과제에서 F의 올바른 중단(해당 파일 미변경 ∧ 이유 = 근거 없음/모순) ≥ 2/3
  4. 과제당 잘못된 이동(틀린 폴더로 옮김) ≤ 0.5
  5. 평가 중 교사 호출 = 0
- **NO GAIN** — F − N ≤ 0 또는 F 완수율 < 0.2.
- 그 외는 **INCONCLUSIVE**.
- **INVALID** — 교사·LLM 호출 시도가 하나라도 있음, ORACLE 완수율 < 1, 소스 변경, 봉인 절차(§5) 위반, 평가 문장·확장자가 훈련 자료와 겹침.
- **2차 지표**(판정 무관, 모두 보고):
  - F − S(대조의 가치)
  - 처음 보는 문장 형태에서의 해석 정확도(봉인된 정답 해석과 비교)
  - 미지 항목 탐지의 적중·누락
  - 정보 행동별 트리거의 타당성(그 시점에 실제로 모르던 것이었나)
  - 최종 채택값별 근거 타당성(인용 문장에 확장자와 값이 실제로 있나)
  - 질의 수, 페이지 수, 서로 다른 도메인 수, 바이트, 소요 시간, 네트워크 실패, robots 거부
  - 실패 사례 분류(해석 / 질의 / 출처 / 추출 / 대조 / 계획 / 환경)
- **알려진 한계**: 목표 형태는 3가지로 제한된다(새 과제 유형이 아니라 표현과 사실의 일반화를 본다). 영어는 어휘 학습 수준이다. 웹은 실행 시점의 상태다. 진실 표가 Python `mimetypes`라서 실제 웹의 다른 관례와 어긋날 수 있다(그런 확장자는 후보에서 제외).

## 8. 구현 순서
1. 웹 클라이언트(robots·속도 제한·보관·재생) + 정보 행동 기록
2. 과제 생성기·진실 표·불가능 과제·평가기 판정
3. 해석기(어휘 학습) + 추출기(패턴 학습) + 결정 절차 + 비교군 N/S/M
4. 교사 모듈(훈련 전용)과 훈련 실행
5. dev 확인(훈련 확장자 일부로 교사를 끄고 시험) → 코드·훈련 자료 동결 → 봉인 → 평가 1회
