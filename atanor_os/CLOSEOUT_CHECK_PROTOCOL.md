# 1세대 마감 확인 — 무엇을 남길지 (구현 전에 고정, 2026-10-27)

사용자 지시(2026-10-27, 방향 전환)에 따라 2~6차 규칙을 정리한다. 기준은 하나다. **새 규칙이 기존 보드·파일·화면의 새 봉인 시드에서 1세대보다 틀린 행동을 늘리면 채택하지 않는다.**

## 이미 정해진 것 (근거가 있어 이 확인으로 다시 재지 않음)
- **채택하지 않음, 코어에서 뺀다:**
  - 나중 결말 규칙(2차)과 그 수정(4차 되돌림, 5차 세계 전체 변화). 새 봉인 시드 92·103·121의 화면 몸에서 1세대보다 틀린 행동이 많았다.
  - 반박 경쟁 보류(6차): 봉인 평가에서 기각되었다.
- **데스크 중복 전송 방지는 코어에서 빼고 데스크 몸으로 옮긴다.** 데스크의 보내기 직전에 상태를 확인한다. 이미 큐에 있거나 보낸 초안이면 다시 보내지 않고, '중복 방지'로 기록한다. 이것은 몸이 제공하는 절차이며 학습기가 배운 것이 아니다. 따라서 평가에서는 학습기의 시도(막힌 수)와 실제 다시 보내기를 따로 보고한다.
- **유지:**
  - 권한을 학습기가 스스로 만들지 못하게 한 수정(권한은 명령을 내린 쪽이 준다; 거절은 반례가 아님)
  - 어댑터 기반 속성 선언(`KIND_ATTRS`)
  - 평가기 수정 여덟과 수식어 시험
