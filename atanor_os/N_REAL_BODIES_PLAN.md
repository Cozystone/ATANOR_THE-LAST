# N단계: 남이 쓴 세계로 배운 읽기 모형이 ATANOR의 실제 몸에서도 모름을 줄이는가 (2026-11-10, 새 시드를 열기 전에 고정)

## 왜

M에서 다른 저자의 세계로 배운 모형은 본 적 없는 저자의 세계로 건너갔다(+7.9 ~ +14.9%p). M3에서 그 몫은 저자 다양성이 아니라 내가 쓰지 않은 세계로 배운 것이었다. 저자 세계끼리는 같은 명세로 쓰였으므로, 어떤 저자도 쓰지 않은 실제 몸에서 확인해야 한다.

## 개발 몸에서 본 것 (시드 1–5, 결과를 본 뒤 이 계획을 씀)

| 읽기 모형 | 혼성 τ0.95 R / W | 혼성 τ0.9 R / W |
|---|---|---|
| 기호 마음 | .549 / .0011 | |
| `meta-k1` (내 문법) | .562 / .0013 | .572 / .0202 |
| `reader-all5` (다섯 저자, 600세계씩, k1에서 6,000걸음) | **.665 / .0011** | .686 / .0105 |

- 개발 몸 여섯에서 τ0.95의 추가 틀림은 0건이다(12 = 12). 이 개발 결과를 보고 이 시험을 정했으므로 개발 결과 자체는 증거가 아니다.

## 시험 (한 번)

- 읽기 모형: `reader-all5.pt`(sha256 앞 16자리 `16c550d864482f7c`), 학습에 실제 몸 자료 없음.
- 몸 여섯(board, clime, desk, dye, fs, view), **과정 시드 1701–1703, 평가 세계 1801–1803**(I단계에서 예약했으나 I가 실패해 열지 않은 시드, 어디에도 쓰지 않음). 과정은 개발과 같은 프로그램 교사(`run_act6.course`), 질의는 `devbench cache`.
- 설정: K·M과 같은 τ0.95, 표결 1, k=10. 바꾸지 않는다.
- 비교: EMPTY(기호 마음), HYBRID-all5, HYBRID-k1(같은 설정).

## 기준

| 기준 | 내용 |
|---|---|
| N1 안전 | 여섯 몸 합계 틀림 증가 ≤ 1%p |
| N2 이득 | 여섯 몸 합계 정답 +3%p 이상, 여섯 중 넷 이상에서 상승 |
| N3 출처 | 여섯 몸 합계 HYBRID-all5 정답 > HYBRID-k1 정답 + 3%p |

- **통과:** N1·N2·N3. **부분:** N1·N2만. **실패:** 그 밖.

## 한계

- 몸 여섯은 개발에 쓴 몸이다. 새 시드는 새 과정과 새 평가 세계이지 새 몸이 아니다. 새 몸은 별도 저자가 만들어야 한다.
- 프로그램 교사 결과다. 실제 사람 결과가 아니다.
- 학습 자료는 ATANOR의 삶이 아니라 남이 쓴 생성 세계다. 기억 기관 하나의 측정이다.
