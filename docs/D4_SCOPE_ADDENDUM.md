# D4 scope clarification before the first fresh execution

An independent read-only design review found no execution-blocking defect for
the registered narrow question. It identified these necessary claim boundaries:

- The 64 lives are independent executions of **two initial relational topology
  templates**, not 64 different mechanisms or structural problem families.
  Handle permutation and visible size vary; raw path names/content bytes are
  not themselves available to the policy. All four goal forms are fixed.
- Paired life bootstrap estimates variation in this supplied distribution,
  conditional on the fixed checkpoints. It is not a confidence bound on
  transfer to new structures, new dynamics, other seeds, or general intelligence.
- Full-context neural is a predeclared, context-corrected comparison, not a
  proven best possible neural model. Its 50% validity floor rejects collapse;
  it does not establish optimal baseline tuning.
- All arms receive the same initial training observations and observation
  access. Their later experiences differ because they select different actions.
- Online updates continue during evaluation goals. The frozen comparison
  measures the effect of the entire online-learning policy, not separately
  knowledge acquired only in the first two goals and reused without updating.
- The relational candidate has an explicit generic KEEP/COPY/constant/role
  grammar. Comparing it with a factorized neural model tests the integrated
  alternatives, not the independent causal contribution of joint effects.

These limitations do not change any candidate, seed, threshold, sample size or
registered source hash. The one final run has not started when this is written.
Positive results would support only local known-mechanics task efficiency and
the separately tested online contribution. They cannot establish AGI progress
in representation invention, new-mechanics transfer, or recursive improvement.
