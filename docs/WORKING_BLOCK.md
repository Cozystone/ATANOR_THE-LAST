## Claims and limits

No LLM, pretrained weights, world-specific solver in the learner/planner,
or automatic modification of production. Runtime uses the existing native
filesystem adapter, including its operation-specific physical implementation.
The cognitive core sees opaque actions and public structured observations.

World persistence is an explicit, dated locator-view journal across goals and
restart. It is not learned object identity, incomplete perception, or a finished
4D substrate. All native outcomes come from the supervisor, not a forecast.
Conditional effect learning still uses a fixed input/program grammar. It is
not invention of new ontological primitives or verified self-evolution.

Mechanism tests cannot establish capability. DEV layouts are exposed and may
only establish readiness. Fresh evaluation must freeze code, model snapshots,
generator, seeds, ordering, stopping, metrics and numerical gates beforehand.
The first comparison is an integrated candidate versus a strong context-aware
baseline plus one frozen-learning ablation, not attribution to every component.
